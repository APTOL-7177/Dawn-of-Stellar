## 2️⃣ 피해량 계산 공식

### 코드 위치
`src/combat/combat_manager.py` 라인 6514-6562

### 계산 과정

```python
# 1단계: 기본 피해 계산
avg_atk = (참여자의 총 공격력) / 참여자 수
base_damage = int(avg_atk * multiplier)

# 2단계: 방어력 적용
actual_damage = max(1, base_damage - defense // 2)

# 3단계: 크리티컬 보장 (critical_guaranteed = true)
if critical_guaranteed:
    actual_damage = int(actual_damage * 1.5)

# 4단계: HP 흡수
if hp_drain_percent > 0:
    drain_amount = int(actual_damage * hp_drain_percent / 100)
    각 참여자 회복 = drain_amount // 참여자수
```

### 문제 1: Hybrid 타입 공격력 중복 계산

**위치**: `combat_manager.py` 라인 6523-6526

**코드**:
```python
for p in participants:
    if damage_type in ("physical", "hybrid"):
        total_atk += getattr(p, 'physical_attack', 50)
    if damage_type in ("magic", "hybrid", "holy", "dark", "tech"):
        total_atk += getattr(p, 'magic_attack', 50)
```

**문제점**:
- Hybrid 타입인 경우 물리 공격력과 마법 공격력을 **모두 더함**
- 평균값 계산 시 영향을 받음
- 실제 피해가 50~100% 높아짐

**예시**:
```
참여자: 물리 공격 100, 마법 공격 80
Hybrid 타입: total_atk = 100 + 80 = 180 → avg_atk = 90
실제로는: (100 + 80) / 2 = 90이어야 함 (우연히 같지만 로직은 잘못됨)

2명 참여 시:
물리: 100 → avg = 50
마법: 80 → avg = 40
Hybrid: 180 → avg = 90 (약 2배 높음!)
```

**수정 방안**:
```python
for p in participants:
    if damage_type == "physical":
        total_atk += getattr(p, 'physical_attack', 50)
    elif damage_type in ("magic", "holy", "dark", "tech"):
        total_atk += getattr(p, 'magic_attack', 50)
    elif damage_type == "hybrid":
        # 물리와 마법의 평균
        phys = getattr(p, 'physical_attack', 50)
        mag = getattr(p, 'magic_attack', 50)
        total_atk += (phys + mag) / 2
```

### 문제 3: 파티 보너스 곱셈 로직 오류

**위치**: `src/combat/job_synergy.py` 라인 267-271

**코드**:
```python
def get_total_bonus_effects(self) -> Dict[str, float]:
    total = {}
    for bonus in self._active_bonuses:
        for key, value in bonus.effects.items():
            if key in total:
                total[key] = total[key] + value - 1.0 if isinstance(value, float) and value > 1.0 else total[key] + value
            else:
                total[key] = value
    return total
```

**문제점**:
- 배수 효과 (1.1, 1.2 등)를 **더하는 방식**으로 계산
- 수학적으로 잘못됨

**예시**:
```
물리 우세: physical_attack_mult = 1.10
magic_supremacy: magic_attack_mult = 1.10

현재 로직: 1.10 + 1.10 - 1.0 = 1.20 (물리 +20%)
정상 로직: 1.10 × 1.10 = 1.21 (물리 +21%)

차이는 작지만 많은 보너스가 겹칠수록 벌어짐
```

**수정 방안**:
```python
def get_total_bonus_effects(self) -> Dict[str, float]:
    total = {}
    mult_keys = {}  # 곱셈 효과 분류
    
    for bonus in self._active_bonuses:
        for key, value in bonus.effects.items():
            if key.endswith('_mult') and isinstance(value, float):
                # 배수는 곱하기
                if key not in mult_keys:
                    mult_keys[key] = 1.0
                mult_keys[key] *= value
            else:
                # 가산값은 더하기
                total[key] = total.get(key, 0) + value
    
    # 곱셈 결과 병합
    total.update(mult_keys)
    return total
```

### 문제 4: 방어력 감소 공식의 취약성

**위치**: `combat_manager.py` 라인 6537

**코드**:
```python
actual_damage = max(1, base_damage - defense // 2)
```

**문제점**:
- 방어력이 높은 적에게 피해가 선형으로 감소
- 게이지 350을 쓴 합체기가 1의 피해만 줄 수 있음

**예시**:
```
절대영도: base_damage ≈ 1000
적 방어: 2100
actual_damage = max(1, 1000 - 1050) = 1 (!!)
```

**개선 방안**:
```python
# 방어력 적용을 비율로 변경
defense_ratio = min(0.8, defense / (defense + 100))
actual_damage = max(1, int(base_damage * (1 - defense_ratio)))
```

if status and hasattr(t, 'status_manager'):

if status and hasattr(t, 'status_manager'):

            "type": "status",

            "duration": duration
        })
