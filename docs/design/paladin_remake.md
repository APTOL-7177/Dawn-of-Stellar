# 성기사 리메이크 안

## 현재 상태 분석

### 기본 컨셉
- **아키타입**: 탱커/서포터
- **슬로건**: "신성한 빛이 어둠을 물리친다"
- **기믹**: 성스러운 힘 (성력 100 축적)

### 현재 문제점

1. **기믹 정체성 부재**
   - 성력 시스템이 단순 MP 대체품 수준
   - 공격/치유 시 축적 → 스킬 사용의 반복
   - 전략적 선택지 부재

2. **탱커/서포터 역할 모호**
   - 두 역할 다 어중간하게 수행
   - 도발이나 강제 타겟팅 없음
   - 방어 스킬이 단순 버프 위주

3. **수동적 플레이**
   - 위기 상황에 대한 능동적 대응 수단 부족
   - 희생의 정신이 30% 확률 피격으로 불확실

4. **특성 시너지 부족**
   - 각 특성이 독립적으로 작동
   - 빌드 다양성 없음

## 리메이크 제안: 서약 시스템 (Oath System)

> "성기사는 신에게 서약을 맹세하고, 서약을 지키는 한 신의 축복을 받는다"

### 핵심 메카닉

```yaml
기믹:
  name: 신성한 서약
  description: |
    전투 시작 시 3가지 서약 중 하나를 선택.
    서약 조건을 충족하면 "신앙" 게이지 상승 (최대 100).
    서약을 어기면 "신앙" 하락 + 일시 디버프.
    신앙 게이지로 강력한 "기적" 스킬 사용.

  신앙 단계:
    - 0~24: 믿음 부족 (기적 사용 불가)
    - 25~49: 신앙인 (소형 기적 사용 가능)
    - 50~74: 축복받은 자 (중형 기적 사용 가능)
    - 75~99: 성인 (대형 기적 사용 가능)
    - 100: 신의 대리인 (궁극 기적 사용 가능)

  서약 전환:
    - "서약 선언" 스킬로 전투 중 언제든 변경 가능
    - 서약 변경 시 현재 신앙 50% 감소
    - 전용 UI 팝업으로 선택
    - 변경 후 즉시 새 서약 조건 적용
    - 현재 서약은 저장 데이터에 보존
```

---

### 서약 종류 (3가지 중 택1)

#### 1. 인내의 서약 (Endurance)
> "고통은 나의 것, 구원은 그대의 것"

```yaml
컨셉: 자신이 파티에서 가장 많은 타수를 받아야 한다 (도트 데미지 제외)

유지 보상:
  - 받는 피해 -25%
  - 피격 시 신앙 +8
  - HP가 낮을수록 방어력 상승 (HP 1%당 방어 +0.5%)

서약 조건:
  - 매 턴 종료 시, 해당 턴에 파티 내 최다 피격 횟수를 받았는지 확인
  - 화상/독/출혈 등 도트 데미지는 타수에서 제외
  
서약 준수:
  - 신앙 +12
  - "인내자의 빛" 버프: 다음 턴 치유 받을 시 +50%
  
서약 위반 (다른 아군이 더 많이 맞음):
  - 신앙 -20
  - 1턴간 "부끄러움": 공격력 -30%
  
전략 포인트:
  - 도발/어그로 관리 필수
  - 기사의 "의무" 시스템과 차별화: 기사는 대신 맞기, 성기사는 본인이 직접 맞기
  - 다단히트 적 상대로 유리 (1타당 낮은 데미지로 여러 번 맞기)
```

#### 2. 순결의 서약 (Purity)
> "오염되지 않은 영혼만이 신을 볼 수 있다"

```yaml
컨셉: 디버프 없이 깨끗한 상태를 유지해야 한다

유지 보상:
  - 상태이상 저항 +40%
  - 디버프 지속시간 -1턴
  - 신앙 매턴 +5 (디버프 없을 시)

서약 조건:
  - 성기사에게 디버프가 없는 상태 유지
  
서약 준수 (디버프 0개 상태로 턴 종료):
  - 신앙 +10
  - 아군 1명 디버프 1개 정화
  
서약 위반 (디버프 2개 이상 중첩):
  - 신앙 -15
  - 1턴간 "오염": 치유 효과 -50%
  
디버프 정화 시:
  - 본인 정화: 신앙 +5
  - 아군 정화: 신앙 +8
  
전략 포인트:
  - 상태이상 해제 스킬 중요도 상승
  - 디버프 많이 거는 보스전에서 도전적
  - 정화 특화 빌드 가능
```

#### 3. 자비의 서약 (Mercy)
> "치유하고 보호하라, 그것이 신의 뜻이니라"

```yaml
컨셉: 아군을 지속적으로 치유하고 지원해야 한다

유지 보상:
  - 치유 효과 +40%
  - 버프 지속시간 +1턴
  - 오버힐 시 보호막 전환 (초과량의 50%)

서약 조건:
  - 매 턴 치유 또는 버프 스킬 1회 이상 사용
  
서약 준수:
  - 신앙 +10
  - 치유 시: 대상 BRV +15% 회복
  - 버프 시: 본인도 같은 버프 50% 효과
  
서약 위반 (2턴 연속 공격만 사용):
  - 신앙 -20
  - 1턴간 "자비 상실": 치유 불가
  
연속 치유/버프 보너스:
  - 2연속: 신앙 +5 추가
  - 3연속: 신앙 +10 추가 + MP 10 회복
  
전략 포인트:
  - 순수 서포터 플레이
  - 공격 타이밍을 잘 조절해야 함
  - 오버힐 → 보호막 전환으로 낭비 없음
```

### 기사와의 차별점

| 항목 | 기사 (Knight) | 성기사 (Paladin) |
|------|---------------|------------------|
| 기믹 | 의무 스택 (0~10) | 신앙 게이지 (0~100) |
| 획득 방식 | 아군 "대신" 피해 받기 | 서약 조건 충족 |
| 리스크 | 없음 (축적만 함) | 서약 위반 시 페널티 |
| 보상 | 의무 비례 방어 버프 | 신앙 단계별 기적 스킬 |
| 역할 | 물리적 방패 | 신성한 수호자 |
| 플레이 | 안정적, 수동적 | 긴장감, 능동적 |

### B안: 수호 대상 시스템 (Guardian Bond) - 대안

> "성기사는 수호 대상을 지정하고, 그의 운명과 함께한다"

```yaml
기믹:
  name: 수호의 연결
  description: |
    전투 시작 시 아군 1명을 "수호 대상"으로 지정.
    수호 대상의 상태에 따라 성기사의 능력 변화.
    수호 대상과의 "결속" 게이지로 강력한 연계기 사용.

핵심 메카닉:
  - 결속 게이지 (0~100):
    - 수호 대상 행동 시: +5
    - 수호 대상 피격 시: +10 
    - 성기사가 수호 대상 치유/버프 시: +15
    - 수호 대상 전투불능 시: 즉시 100 (분노 모드)

수호 상태 효과:
  - 안전 (수호 대상 HP 70%+):
    - 성기사: 치유 효과 +30%
    - 수호 대상: 받는 피해 -15%
    
  - 위기 (수호 대상 HP 30~70%):
    - 성기사: 공격력 +20%, 도발 자동 발동
    - 수호 대상: 회피 +20%
    
  - 위독 (수호 대상 HP 30% 미만):
    - 성기사: 모든 스킬 쿨다운 -1, 속도 +50%
    - 자동으로 수호 대상 앞에 방어 태세
    
  - 분노 (수호 대상 전투불능):
    - 성기사: 공격력 +100%, 방어 -30%
    - 신성 속성 → 복수의 불꽃 (화염 속성 추가)
    - "복수의 일격" 스킬 해금 (결속 100 소모)

연계 스킬 (결속 게이지 소모):
  - 30: "수호의 쇄도" - 수호 대상의 위치로 순간이동 + 피해 흡수
  - 50: "영혼의 사슬" - 5턴간 수호 대상 받는 피해 50% 분담
  - 75: "거울 심판" - 다음 공격을 수호 대상 대신 받고 반사
  - 100: "신성한 부활" - 수호 대상 전투불능 시 HP 50%로 부활

장점:
  - 파티 내 관계성 강조
  - 수호 대상 선택에 따른 전략 변화
  - 위기 상황에서 더 강해지는 역전 요소
  - 감정적 몰입도 높음
  
단점:
  - 수호 대상이 죽으면 분노 모드가 너무 강할 수 있음
```

## 상세 설계 (서약 시스템)

### 1. 스킬 재설계

#### 기본 스킬

| 스킬명 | 유형 | 효과 | 신앙 획득 |
|--------|------|------|----------|
| 서약 선언 | 기믹 | 전투 중 언제든 서약 UI 열기 + 선택/변경 | 변경 시 -50% |
| 신성 타격 | 공격 | BRV 1.8 + HP 1.5 | +3 |
| 심판의 빛 | 공격 | BRV 2.2 + HP 1.8, 언데드 +50% | +5 |
| 성스러운 방패 | 방어 | 자신 피해 -40% 1턴, 도발 | +8 (인내) |
| 치유의 손길 | 치유 | 단일 HP 35% 회복 | +10 (자비) |
| 축복 | 버프 | 단일 공/방 +15% 3턴 | +8 (자비) |
| 정화의 빛 | 정화 | 아군 디버프 2개 해제 | +10 (순결) |
| 성수 뿌리기 | 정화 | 전체 디버프 1개 해제 | +15 (순결) |

#### 기적 스킬 (신앙 소모)

| 스킬명 | 필요 신앙 | 소모 | 효과 |
|--------|-----------|------|------|
| 작은 기적 | 25+ | 25 | 단일 HP 25% 회복 + 디버프 1개 해제 |
| 보호의 기적 | 50+ | 40 | 전체 아군 피해 -30% 2턴 |
| 치유의 기적 | 50+ | 50 | 전체 HP 30% 회복 |
| 부활의 기적 | 75+ | 75 | 전투불능 아군 1명 HP 40% 부활 |
| 정화의 기적 | 75+ | 60 | 전체 디버프 전부 해제 + 3턴 면역 |
| 신의 심판 | 100 | 100 | 전체 적 HP 4.0 + 언데드 즉사 |
| 신의 은총 | 100 | 100 | 전체 아군 HP 전회복 + 버프 전부 갱신 |

### 2. 특성 재정비

| 특성 | 현재 | 제안 |
|------|------|------|
| 신성한 가호 | 치명타 30% 무효화 | 신앙 50+ 시 파티 치명타 무효화 |
| 성스러운 오라 | 방어력 +15% | 서약 준수 중 파티 방어 +20% |
| 희생의 정신 | 30% 대신 피격 | 인내 서약 전용: 대신 맞기 가능 + 신앙 +15 |
| 치유의 빛 | 회복 +35% | 자비 서약 전용: 치유 시 신앙 +5 추가 |
| 정의의 분노 | 아군 전투불능 시 공격 +40% | 서약 위반 시 페널티 50% 감소 |

### 3. 팀워크 스킬

**현재**: 기록 없음

**제안**:
```
"삼위일체의 축복"
- 3가지 서약의 효과를 동시에 2턴간 발동
- 순교: 파티 받는 피해 -20%
- 순결: 파티 디버프 전해제
- 자비: 파티 HP 25% 회복
- 신앙 +30
- 현재 서약 유지 (위반 체크 일시 중단)
```

### 4. 궁극기 개선

**현재**: 불명확

**제안** (서약별 분기):
```
"신의 대리인" (신앙 100 필요)

[인내 서약 시] - 인내자의 승천
- 자신 HP 1로 감소
- 파티 전원 HP 전회복 + 3턴 무적
- 이후 5턴간 "불멸": HP 1 이하로 안 떨어짐

[순결 서약 시] - 정화의 성역
- 필드 전체 "성역" 5턴
- 성역: 모든 디버프 즉시 해제 + 면역
- 적 버프 전부 해제 + 3턴 버프 불가

[자비 서약 시] - 무한한 자비
- 파티 전원 HP 전회복
- 전투불능 아군 전부 부활 (HP 50%)
- 5턴간 "은총": 매턴 HP 10% 자동 회복
```

## 시너지 예시

### 서약별 추천 파티 조합

| 서약 | 추천 조합 | 이유 |
|------|-----------|------|
| 인내 | 힐러 + 딜러 2명 | 성기사가 탱킹, 힐러가 유지보수 |
| 순결 | 광역딜러 + 버퍼 | 디버프 관리로 안정적 공세 |
| 자비 | 탱커 + 딜러 2명 | 성기사가 서포터, 탱커가 어그로 |

### 서약 전략 플로우차트

```
전투 시작
  ↓
적 구성 확인
  ↓
┌─ 디버프 많은 적 → 순결의 서약
├─ 다단히트/광역 공격 적 → 인내의 서약  
└─ 장기전 보스 → 자비의 서약
  │
(상황 변화 시)
  ↓
"서약 선언" 스킬로 서약 변경 (UI 팝업)
  ↓
신앙 50% 감소 후 새 서약 시작
  ↓
서약 유지하며 신앙 축적
  ↓
신앙 75+ 달성
  ↓
상황에 맞는 기적 사용
  ↓
신앙 100 → 궁극 기적으로 전투 마무리
```

### 서약 위반 복구 전략

```
서약 위반 발생!
  ↓
신앙 -15~20, 디버프 1턴
  ↓
복구 방법:
  - 다음 턴 반드시 서약 조건 충족
  - 정의의 분노 특성: 페널티 50% 감소
  - 연속 서약 준수로 보너스 신앙 획득
```

1. 🔲 서약 선택/변경 UI 구현 (전투 중 팝업)
2. 🔲 신앙 게이지 시스템 구현 (0~100)

6. 🔲 저장 시스템 연동 (paladin_oath 데이터)
7. 🔲 기적 스킬 7종 추가
8. 🔲 특성 재정비
9. 🔲 서약별 궁극기 분기
10. 🔲 팀워크 스킬 구현
11. 🔲 UI 표시 (신앙 게이지, 서약 아이콘, 변경 버튼)

## 밸런스 고려사항

### 수치 조정 필요

- 신앙 획득량: 서약에 따라 5~15 / 턴, 10턴 내 100 도달 가능하도록
- 서약 위반 페널티: 너무 가혹하지 않게 (1턴 디버프 + 신앙 -15~20)
- 부활의 기적: 전투당 1회 제한 권장
- 궁극 기적: 신앙 100 전부 소모

### 카운터 플레이

- 인내 서약: 적이 성기사 무시하고 다른 아군 공격 → 위반 유도
- 순결 서약: 디버프 폭탄 보스 → 유지 어려움
- 자비 서약: 매턴 치유 강제 → MP 관리 중요
- "신앙 감소" 디버프 보스 스킬 추가 가능

## 저장 시스템 연동

```yaml
저장 데이터:
  paladin_oath:
    current_oath: "endurance"  # endurance / purity / mercy
    faith_gauge: 72
    consecutive_compliance: 3  # 연속 서약 준수 횟수
    total_oath_changes: 2      # 해당 전투에서 서약 변경 횟수
    
저장 시점:
  - 전투 중 턴 종료 시
  - 서약 변경 시
  - 전투 종료 시 (faith_gauge 리셋 or 유지 여부 결정)
  
로드 시점:
  - 전투 재개 시 마지막 상태 복원
  - 중단 후 재접속 시 UI 상태 복원
```
