# 신관 리메이크 안

**작성일**: 2025-12-03
**버전**: 1.0

---

## 현재 상태 분석

### 기본 컨셉
- **아키타입**: 기적/치유 특화
- **슬로건**: "구원할 것인가, 심판할 것인가"
- **기믹**: 신성 권능 (신앙 100 / 심판력 100 이중 게이지)

### 현재 문제점

1. **이중 게이지 관리 복잡**
   - 신앙과 심판력을 동시에 관리해야 함
   - 어느 쪽에 집중할지 애매함
   - 신성 균형 특성(신앙=심판력)이 현실적으로 달성 어려움

2. **수동적 기믹**
   - 100 도달 시 "자동" 발동이라 플레이어 선택권 부족
   - 축적만 하면 되는 단순한 플레이

3. **예측 불가능한 타이밍**
   - 부활/무적이 언제 터질지 컨트롤 어려움
   - 전략적 사용보다는 우연에 의존

4. **힐러 vs 딜러 정체성 혼란**
   - 치유 특화인데 심판(공격) 스킬도 많음
   - 둘 다 어중간하게 수행

## 리메이크 제안: 신탁 시스템 (Divine Oracle System)

> "신의 뜻을 듣고 따르는 자, 기적을 일으키리라"

### 핵심 컨셉

매 턴 **신탁(Oracle)**을 받아 조건을 충족하면 강력한 보상을 얻는 **예언 기반 플레이**.
신의 뜻을 따를지, 거스를지 선택하는 긴장감 있는 의사결정.

```yaml
기믹:
  name: 신탁 시스템
  description: |
    매 턴 시작 시 "신탁"을 받음 (3가지 중 무작위).
    신탁 조건 충족 시: 신앙 +15~25, 추가 효과 발동
    신탁 무시/위반 시: 신앙 변화 없음
    
    신앙 게이지 (0~100)로 기적 스킬 사용.
    
  신앙 단계:
    - 0~24: 구도자 (기적 불가)
    - 25~49: 신앙인 (소형 기적)
    - 50~74: 사제 (중형 기적)
    - 75~99: 대사제 (대형 기적)
    - 100: 성자 (궁극 기적)

  특수 메카닉:
    - "신탁 거부": 현재 신탁을 무시하고 자유롭게 행동 (패널티 없음)
    - "신탁 갱신": 10 신앙 소모로 새로운 신탁 받기
    - "절대 신앙": 3연속 신탁 충족 시 다음 기적 강화
```

## 신탁 종류 (6가지)

### 1. 치유의 신탁 (Oracle of Healing)
> "상처받은 자를 돌보라"

```yaml
조건: 이번 턴에 아군을 치유하라
충족 대상: HP가 100% 미만인 아군 누구든

충족 시:
  - 신앙 +20
  - "치유의 은총": 치유량 50% 추가 회복
  - 치유 대상에게 "신의 가호" 1턴 (받는 피해 -20%)

특수:
  - HP 50% 미만 아군 치유 시: 신앙 +30
  - 전체 치유 시: 추가로 신앙 +10
```

### 2. 심판의 신탁 (Oracle of Judgment)
> "악을 응징하라"

```yaml
조건: 이번 턴에 적을 공격하라

충족 시:
  - 신앙 +15
  - "심판의 빛": 해당 공격에 신성 속성 추가, 데미지 +25%
  - 언데드/악마 유형 적에게 +50% 추가 피해

특수:
  - BREAK 발생 시: 신앙 +25
  - 적 처치 시: 신앙 +35 + MP 15 회복
```

### 3. 수호의 신탁 (Oracle of Protection)
> "약한 자를 지키라"

```yaml
조건: 이번 턴에 아군에게 버프 또는 보호막을 부여하라

충족 시:
  - 신앙 +18
  - "수호의 축복": 버프 지속시간 +1턴
  - 대상에게 추가로 HP 10% 회복

특수:
  - HP가 가장 낮은 아군 버프 시: 신앙 +28
  - 전체 버프 시: 추가로 신앙 +12
```

### 4. 정화의 신탁 (Oracle of Purification)
> "더러움을 씻어내라"

```yaml
조건: 이번 턴에 디버프를 해제하라

충족 시:
  - 신앙 +22
  - "정화의 빛": 해제된 디버프 수 × 5 추가 신앙
  - 정화 대상 HP 8% 회복

특수:
  - 치명적 디버프(기절/혼란/동결) 해제 시: 신앙 +35
  - 아군 전체 정화 시: 신앙 +40

조건 불가 시:
  - 디버프가 없는 상황이면 자동으로 다른 신탁으로 교체
```

### 5. 인내의 신탁 (Oracle of Endurance)
> "고통을 감내하라"

```yaml
조건: 이번 턴에 피해를 받아라 (아군 대신 받기 포함)

충족 시:
  - 신앙 +20
  - "고행자의 빛": 받은 피해의 30% HP 회복
  - 다음 턴 받는 피해 -25%

특수:
  - HP 30% 이하에서 피격 시: 신앙 +30 + "불굴" (HP 1에서 생존 1회)
  - 아군 대신 피해 받기 시: 신앙 +35
```

### 6. 침묵의 신탁 (Oracle of Silence)
> "말없이 기도하라"

```yaml
조건: 이번 턴에 공격/치유 스킬을 사용하지 마라 (방어/대기만 가능)

충족 시:
  - 신앙 +25
  - "명상의 시간": MP 20% 회복
  - 다음 턴 모든 스킬 효과 +40%
  - ATB 보너스 +30

특수:
  - 2연속 침묵 신탁 충족 시: 신앙 +40 + 기적 1회 무료 사용
```

## 신탁 메카닉 상세

### 신탁 결정 확률

```yaml
기본 확률:
  치유의 신탁: 25%
  심판의 신탁: 20%
  수호의 신탁: 20%
  정화의 신탁: 15%
  인내의 신탁: 12%
  침묵의 신탁: 8%

상황별 가중치:
  - 아군 HP 50% 미만 존재: 치유/수호 확률 +15%
  - 아군 디버프 2개+ 존재: 정화 확률 +20%
  - 신관 HP 70% 이상: 인내 확률 +10%
  - 보스전: 침묵 확률 -5% (너무 불리하지 않게)
```

### 신탁 갱신 시스템

```yaml
스킬명: 신탁 갱신
MP: 0
신앙 소모: 10
효과:
  - 현재 신탁 취소
  - 즉시 새로운 신탁 받음
  - 같은 신탁이 연속으로 나오지 않음 보장

전략적 사용:
  - 수행 불가능한 신탁이 나왔을 때
  - 특정 신탁이 필요할 때 (확률 도박)
```

### 절대 신앙 (3연속 충족 보너스)

```yaml
조건: 3턴 연속으로 신탁 충족

보상:
  - "신의 총애" 3턴 버프
    - 모든 스킬 효과 +30%
    - 기적 MP 소모 -50%
    - 신앙 획득량 +50%
  - 다음 기적 스킬 즉시 사용 가능 (쿨다운 무시)

추가:
  - 5연속 충족 시: "성자의 경지" - 궁극 기적 1회 무료 해금
```

| 상황 | 추천 조합 | 이유 |
|------|-----------|------|

| 공격형 | 딜러 3명 | 심판 신탁 중심, 빠른 전투 |


## 밸런스 고려사항

### 수치 조정

- **신앙 획득**: 신탁 충족 시 평균 +20, 10턴 내 100 도달 가능
- **신탁 갱신**: 10 신앙 소모 = 한 번의 작은 손실, 남발 방지
- **기적 비용**: 신앙 + MP 이중 소모로 과도한 연발 방지
- **부활 제한**: 전투당 부활 2회 제한 권장

### 카운터 플레이

- **신앙 감소 보스 스킬**: 신앙 -20~30 공격으로 기적 타이밍 방해
- **신탁 봉인**: 특정 보스가 3턴간 신탁 발생 막기
- **정화 불가 디버프**: 신관 자체를 무력화

## 대안: B안 - 의식 시스템 (Ritual System)

> "정해진 순서로 행동하면 강력한 의식이 완성된다"

```yaml
기믹:
  name: 신성 의식
  description: |
    특정 스킬을 정해진 순서로 사용하면 의식 완성.
    의식 완성 시 강력한 추가 효과 발동.
    
의식 예시:
  - "치유의 의식": 치유 → 버프 → 치유 = 전체 HP 50% 회복
  - "심판의 의식": 공격 → 공격 → 공격 = 전체 신성 폭발
  - "수호의 의식": 방어 → 버프 → 방어 = 파티 3턴 무적
  - "정화의 의식": 정화 → 치유 → 정화 = 모든 디버프 영구 면역 (전투간)

장점:
  - 패턴 암기 재미
  - 명확한 목표
  
단점:
  - 융통성 부족
  - 의식 중간에 급한 상황 오면 난감
```
