# 검투사 리메이크 안

## 현재 상태 분석

### 기본 컨셉
- **아키타입**: 반격 전문가
- **슬로건**: "관중이 열광할수록 나는 강해진다"
- **기믹**: 군중의 환호 (0~100)

### 현재 문제점

1. **환호 획득/유지의 어려움**
   - 크리티컬 +10, 처치 +20으로는 100 도달이 느림
   - 피격 시 -10은 탱커가 아닌데도 불가피하게 발생
   - 환호 100 도달 전에 전투가 끝나거나 검투사가 죽음

2. **반격 전문가 정체성 부재**
   - 아키타입은 반격 전문가인데 반격 관련 기믹이 없음
   - counter_rate 15%가 있지만 기믹과 연계 없음

3. **수동적 플레이**
   - 환호를 올리기 위해 크리티컬을 기다리는 수동적 플레이
   - 플레이어가 능동적으로 환호를 조절할 방법 부족

4. **리스크-리워드 미흡**
   - 화려한 전투가라는 컨셉에 비해 위험 감수 요소 부족
   - 안전하게 플레이하면 환호가 안 오르고, 공격적으로 플레이할 동기 부족

## 리메이크 제안: 콜로세움 쇼타임 시스템 (Colosseum Showtime)

> "관중이 원하는 건 화려함이다. 그들의 기대에 부응하라!"

### 핵심 메카닉

```yaml
기믹:
  name: 콜로세움의 영광
  description: |
    관중의 요구를 충족시켜 환호를 최대로 끌어올려라!
    
    매 라운드 시작 시 "관중의 요구"가 발표됨.
    요구를 충족하면 환호 대량 획득 + 보너스 효과.
    요구를 무시하면 야유를 받아 환호 감소 + 디버프.
    
    환호가 높을수록 모든 능력이 강화되며,
    100에 도달하면 "그랜드 피날레"를 발동할 수 있다!

  환호 단계:
    - 0~29: 무명 (관중 무관심, 기본 상태)
    - 30~59: 신인 (공격 +15%, 속도 +10%)
    - 60~79: 인기검투사 (공격 +30%, 크리 +15%, 반격률 +20%)
    - 80~99: 챔피언 (공격 +50%, 크리 +25%, 반격률 +30%, 회피 +15%)
    - 100: 전설 (그랜드 피날레 발동 가능!)
```

### 관중의 요구 시스템 (Crowd Demands)

> "관중은 변덕스럽다. 그들이 원하는 것을 파악하고 응해라!"

#### 요구 종류 (매 라운드 1~2개 무작위)

| 요구 | 조건 | 환호 보상 | 보너스 효과 |
|------|------|----------|-------------|
| **"피를 보여줘!"** | 해당 라운드에 적 1명 처치 | +25 | 다음 공격 데미지 +50% |
| **"반격이다!"** | 반격 1회 이상 성공 | +20 | 반격 시 BRV +30 추가 |
| **"화려하게!"** | 크리티컬 2회 이상 | +20 | 크리티컬 데미지 +30% (3턴) |
| **"버텨봐!"** | 검투사가 피격 후 생존 | +15 | HP 회복 15% |
| **"빠르게!"** | 2회 이상 행동 | +20 | 다음 턴 선제 행동 |
| **"한 방!"** | 단일 공격으로 HP 30% 이상 | +25 | 대상에게 "공포" 2턴 |
| **"난전!"** | 3명 이상 적에게 데미지 | +20 | 전체 적 방어 -10% (2턴) |
| **"결투!"** | 같은 적을 2회 연속 공격 | +15 | 해당 적에게 +20% 추가 피해 |

#### 요구 실패 시 (야유)

```yaml
야유 효과:
  - 환호 -15
  - "야유" 디버프 1턴: 공격력 -15%, 크리티컬 -10%
  - 연속 3회 야유 시: "관중 이탈" - 환호 50% 감소
```

#### 요구 난이도 조절

```yaml
요구 선택 로직:
  - 환호 0~29: 쉬운 요구 1개 (버텨봐, 화려하게)
  - 환호 30~59: 보통 요구 1개 (피를 보여줘, 반격이다)
  - 환호 60~79: 보통 요구 2개 또는 어려운 요구 1개
  - 환호 80~99: 어려운 요구 2개 (한 방, 난전, 결투)
  
전략적 선택:
  - "기대치 조절" 스킬로 요구 재추첨 가능 (1라운드 1회)
  - 특정 요구를 지정할 수는 없지만 회피 가능
```

### 시그니처 메카닉: 그랜드 피날레

> "이것이 진정한 쇼다!"

```yaml
그랜드 피날레:
  조건: 환호 100 도달
  효과: |
    [즉시 발동 선택 가능]
    환호 100을 전부 소모하여 궁극의 공연을 펼친다.
    
    선택지 3가지 중 1가지 선택:
    
    1. "황제의 심판" (공격형)
       - 전체 적에게 HP 4.5 데미지
       - 대상 중 HP 가장 낮은 적 즉시 처형
       - 처형 성공 시 환호 30 유지
    
    2. "불사의 챔피언" (방어형)
       - 3턴간 무적
       - 무적 중 피격 시 반격 100% 발동
       - 반격 데미지 +100%
    
    3. "전설의 귀환" (유틸형)
       - HP/MP 전회복
       - 모든 스킬 쿨다운 초기화
       - 5턴간 "전설" 버프: 모든 요구 보상 2배
       
  그랜드 피날레 후:
    - 환호 0 또는 30으로 리셋 (선택에 따라)
    - 다음 라운드 요구 난이도 쉬움으로 시작
```

### 반격 시스템 강화

> "공격은 최고의 방어다. 아니, 반격이야말로!"

```yaml
반격 특화:
  기본 반격률: 20% (기존 15%에서 상향)
  
  반격 트리거:
    - 일반 피격 시: 20%
    - 도발 상태에서 피격: 35%
    - "투기의 자세" 버프 중 피격: 50%
    - 환호 80+ 상태에서 피격: 기본 +15%
  
  반격 효과:
    - 기본: 물리 공격력 100% 데미지
    - 환호 30+: 반격 시 환호 +5
    - 환호 60+: 반격 데미지 +30%
    - 환호 80+: 반격 시 BRV 회복 50
    
  "완벽한 반격" (타이밍 시스템):
    - 피격 직전 "반격 준비" 사용 시
    - 반격 100% 발동 + 데미지 200%
    - 환호 +15, 관중 요구 무조건 충족 취급
```

## 시너지 예시

### 추천 파티 조합

| 조합 | 추천 동료 | 이유 |
|------|-----------|------|
| 반격 특화 | 기사 + 힐러 + 딜러 | 기사가 메인 탱킹, 검투사는 서브탱킹+딜링 |
| 처치 특화 | 암살자 + 마법사 + 버퍼 | 빠른 처치로 "피를 보여줘" 요구 쉽게 충족 |
| 크리 특화 | 궁수 + 음유시인 + 탱커 | 크리티컬 버프로 "화려하게" 요구 쉽게 충족 |

### 시너지 직업

- **음유시인**: 버프가 크리티컬률 상승 → 환호 획득 용이
- **기사**: 의무로 피해 대신 받아줌 → 검투사 피격 감소 → 환호 유지
- **암살자**: 처치 보조로 "피를 보여줘" 요구 충족 쉬움
- **연금술사**: 아이템으로 스탯 버프 → 반격 데미지 상승

## 밸런스 고려사항

### 수치 조정

- 요구 충족 환호: +15~25 (난이도별)
- 야유 페널티: -15 + 디버프 1턴 (너무 가혹하지 않게)
- 환호 100 도달: 평균 4~5라운드 (요구 충족 기준)
- 그랜드 피날레: 전투당 1~2회 발동 가능하도록

### 카운터 플레이

- 관중 요구가 운에 의존 → "기대치 조절"로 재추첨 가능
- 반격 의존 빌드 → 마법 공격 위주 적에게 불리 (반격 불가)
- 처치 요구 → 보스전에서는 "도전자" 특성으로 보완
- 야유 누적 → "쇼스토퍼" 특성으로 완화

### 난이도별 조정

```yaml
일반 전투:
  - 쉬운 요구 위주
  - 환호 100 도달 쉬움
  
보스 전투:
  - 어려운 요구 빈출
  - "도전자" 특성으로 환호 획득량 보정
  - 보스 처치 시 환호 +50
```

## 기존 기믹과의 비교

| 항목 | 기존 | 리메이크 |
|------|------|----------|
| 환호 획득 | 크리/처치/생존 (수동적) | 관중 요구 충족 (능동적) |
