# 메인 탱커 방어형 스킬 설계서

최종 업데이트: 2025-12-02
담당: Cascade (AI 보조)

## 1. 목표
기사/성기사뿐 아니라 파티의 주 방어선이 될 수 있는 직업(전사, 기사, 성기사, 환술사, 차원술사 등)의 **방어력·마법방어력**을 핵심으로 하는 신규 스킬 아이디어를 정의한다. 본 문서는 기획 검토용 초안이며, 실제 구현 시 수치 조정 및 밸런싱이 필요하다.

## 2. 대상 직업 요약
| 직업 | 기믹/특징 | 역할 메모 |
| --- | --- | --- |
| 전사 | 6단계 스탠스 시스템 (stance_system) | 밸런스형 탱/딜, 스탠스별 보정 |
| 기사 | 의무 게이지 (duty_system) | 보호·지휘 특화 탱커 |
| 성기사 | holy_system + 치유/보호 | 파티 보호, 치유 지원 |
| 환술사 | phantom_legion + 회피/분산 | 회피 기반 탱커 |
| 차원술사 | dimension_refraction | 피해 지연·전환형 탱커 |

## 3. 스킬 설계
각 직업별로 방어 관련 선택지를 확장한다. 수치는 플레이테스트 기준으로 3턴 지속/쿨다운 없음 가정.

### 3.1 전사 (Warrior)
1. **강철 수호진 (Steel Bulwark)**
   - 유형: 자기 버프 (stance 전환 없음)
   - 효과: 방어력/마법방어력 +35%, 피해 경감 20%, 다음 스탠스 변경 시 버프 소멸
   - 의도: 스탠스 전환 사이클 중 잠깐의 방어 공백을 메움.
2. **수호 결속 (Guardian Link)**
   - 유형: 자기 지속 버프
   - 효과: 현재 수호자 자세일 때 파티 전체 방어력, 마법방어력 +15%, 전사가 받는 피해 10% 추가 경감 (stance_damage_reduction과 별도)
   - 의도: 수호자 자세의 파티 기여도 상향.

### 3.2 기사 (Knight)
1. **의무 방벽 (Duty Bulwark)**
   - 조건: 의무 3 이상 보유 시 사용 가능
   - 효과: 의무 3 소비 → 방어력/마법방어력 +45%, 의무 스택당 피해 경감 5% 추가, 지속 3턴
   - 시스템: duty_system에 “버프 사용 시 소비 처리” 필요.
2. **실드 라인 (Shield Line)**
   - 유형: 파티 버프
   - 효과: 자신 포함 아군 1명 선택, 방어력/마법방어력 +50%, 자신은 대신 피해 40%를 공유 (cover 효과와 병행)
   - 의도: 보호 역할을 복수의 타겟까지 확장.

### 3.3 성기사 (Paladin)
1. **축복의 방패 (Aegis of Grace)**
   - 효과: 자신 방어력 +30%, 마법방어력 +30%, 피해 경감 15%, 동시에 성력 20 회복
   - 추가: 성력 60 이상일 때 사용 시 파티 전체 마법방어력 +15%
2. **빛의 벽 (Radiant Barrier)**
   - 효과: 파티 전체에 HP 비례 보호막 + 방어력 20% 증가, 보호막이 남아있는 동안 마법방어력 10% 증가
   - 지속: 보호막이 깨질 때까지 또는 2턴.

### 3.4 환술사 (Illusionist)
1. **거울 감응 (Mirror Resonance)**
   - 효과: 환영 수가 3개 이상일 때 방어력 +25%, 마법방어력 +25%, 회피 성공 시 환영 1개 자동 복구
   - 의도: 회피 기반 탱커의 안정성 강화.
2. **환영 장막 (Phantom Aegis)**
   - 효과: 자신이 받는 피해 50%를 환영이 대신 받음, 피해를 받은 환영은 즉시 파괴
   - 메모: phantom_legion 시스템에 “피해 분산” 로직 추가 필요.

### 3.5 차원술사 (Dimensionist)
1. **굴절 증폭기 (Refraction Amplifier)**
   - 효과: 차원 굴절 경감률 +15% (예: 85%→100% 캡), 굴절량 30%를 즉시 보호막으로 변환
   - 지속: 2턴, 쿨다운 5턴 권장
2. **시간 고정 (Temporal Brace)**
   - 효과: 방어력/마법방어력 +40%, 모든 지연 피해 적용 전 1회 면역, 면역 발동 시 MP 10 소모
   - 의도: 폭발적 피해 대응.

## 4. 구현 메모
- BuffEffect로 처리 가능한 항목은 YAML 정의로도 대응 가능. 단, stance_damage_reduction/phantom_legion/dimension_refraction 등 기믹 연동은 GimmickUpdater 보완 필요.
- 스킬 ID: `warrior_steel_bulwark`, `knight_duty_bulwark` 등 일관된 네이밍 권장.
- 수치 검증: 탱커 평균 방어력 70~90, 마방 60~80 기준으로 30~40% 버프는 약 +20~30 방어력 수준.
- 파티 전체 버프는 성기사/기사 한정으로 유지하여 역할 차별화.
