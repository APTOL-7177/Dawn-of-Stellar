# 사무라이 리메이크 안

## 📖 빠른 요약 (TL;DR)

### 🎯 핵심 컨셉
**검심(剣心) - 관찰과 반격의 도**: 적의 공격을 학습하고 패링하여 역이용하는 완벽한 카운터 전사

### ⚔️ 3대 핵심 메커니즘

1. **관찰 시스템 (0~10+ 스택)**
   - 적의 공격을 받거나 방어할 때 스택 축적
   - 3단계 각성: 초심(0-4) → 무심(5-9) → 검성(10+)
   - 단계가 높을수록 패링률 상승 (40% → 65% → 90%)

2. **패링 시스템 (사무라이 전용 방어) ⭐**
   - **미키리 카마에**: 최대 3회 패링 가능 (암흑기사는 1회)
   - 패링 성공률 **100%** (확정 방어!)
   - 효과: 피해 100% 무효 + 강제 반격 + 검압 대량 획득
   - **기의 타테**: 아군 1명을 보호하는 패링 (힐러 보호 가능!)

3. **적 BRV 흡수 (유일무이)**
   - **미키리(見切り)**: 적의 쌓인 BRV 50~80% 흡수
   - 적이 BRV를 쌓을 때까지 기다렸다가 탈취
   - 흡수한 BRV로 즉시 HP 공격 → 적의 힘을 역이용!

### 💥 패링형 궁극기 (타이밍 리워드)
- **무소켄**: 적 공격 타이밍 사용 시 BRV 4.0 + HP 4.0, 평시 BRV 2.0 + HP 1.5
- **텐치쥬잔**: 적 공격 타이밍 사용 시 HP 6.0 + BRV 초기화, 평시 HP 2.5
- **무료타이가**: 적 공격 타이밍 사용 시 전체 HP 5.0 + 무적 3턴, 평시 HP 2.0

  **타이밍 = "요미"로 적 공격을 예측하고 그 순간에 사용!**

### 🎮 플레이 스타일
1. 미키리 카마에로 패링 3회 준비 (100% 확정 방어)
2. 적의 공격을 패링으로 막으며 관찰 스택 축적
3. "요미"로 적의 다음 행동 예측 (2턴간 지속)
4. 검성 도달 (반격 데미지 +80%)
5. 적 BRV가 쌓이면 "미키리"로 대량 흡수
6. 적이 공격할 타이밍에 패링형 궁극기 사용 → 괴멸적 피해!

### 🆚 차별화 포인트
| 특징 | 사무라이만의 강점 |
|------|-------------------|
| **3회 패링** | 암흑기사(1회)보다 3배 많은 패링 기회 (100% 확정) |
| **적 행동 예측** | "요미"로 적의 다음 행동을 미리 확인 (2~3턴) |
| **아군 보호** | 기의 타테로 힐러/마법사 보호 가능 |
| **BRV 흡수** | 적의 BRV를 자신의 것으로 (전 직업 유일) |
| **타이밍 궁극기** | 적 공격 타이밍에 사용 시 2배 효과 |
| **일본어 스킬명** | 분위기 있는 일본어 한글 표기 |

## 현재 상태 분석

### 기본 컨셉
- **아키타입**: 명예의 전사
- **슬로건**: "일도양단, 한 번의 베기에 모든 것을 건다"
- **기믹**: 거합의 도 (iaijutsu_system)

### 현재 문제점

1. **거합 시스템의 모호함**
   - "의지 게이지"가 무엇인지 불명확
   - 다른 직업의 자원 관리 시스템과 차별화 부족
   - 단순한 게이지 충전 → 소비 구조

2. **명예와 의리 컨셉 미활용**
   - 컨셉은 "명예를 중시하는 무사"인데 기믹에 반영 안 됨
   - 무사도, 발도술 등 특성이 수동적
   - 일도양단의 긴장감 부족

3. **리스크-리워드 부재**
   - 안전한 플레이와 위험한 플레이의 차이 없음
   - 완벽한 타이밍을 요구하는 메커니즘 부재
   - 사무라이 특유의 "한 방" 느낌 부족

4. **적과의 상호작용 부족**
   - 적의 행동에 반응하는 메커니즘 없음
   - 패링/카운터 전문가로서의 정체성 부재
   - 적의 공격을 이용하는 플레이 불가능

## 리메이크 제안: 검심(剣心) - 관찰과 반격의 도

> "검을 든 자는 상대의 검을 읽어야 한다. 그것이 검의 도(道)다."

### 핵심 메카닉

```yaml
기믹:
  name: 검심(剣心) - 관찰과 반격의 도
  description: |
    적의 공격을 관찰하고 학습하여 완벽한 반격을 수행한다.

    적의 공격을 받거나 방어할 때마다 "관찰 스택"이 축적된다.
    관찰 스택이 쌓이면 검심의 경지가 깊어져 강력한 반격 능력을 얻는다.

    적의 공격을 견뎌내어 "검압(剣圧)"을 축적하고,
    완벽한 타이밍에 "베어넘기기"로 적의 BRV를 흡수한다.

    궁극의 경지 "검성(剣聖)"에 도달하면 모든 공격을 완벽히 읽고 반격한다!

  검심 3단계:
    - 초심(平心, 0~4 스택): 기본 상태, 반격률 20%
    - 무심(無心, 5~9 스택): 반격률 40%, 카운터 데미지 +30%
    - 검성(剣聖, 10+ 스택): 반격률 70%, 카운터 데미지 +80%, 특수 능력 해금

  검압 게이지:
    - 최대 100
    - 피격 시 적 공격력의 15% 획득
    - 방어/회피 성공 시 20 획득
    - 카운터 성공 시 25 획득
    - 검압 소모로 강력한 기술 사용
```

## 1. 관찰 시스템 (Observation System)

> "천 번의 공격을 견디면, 천 번째 검은 보이지 않는다."

### 관찰 스택 획득

| 행동 | 획득량 | 조건 |
|------|--------|------|
| **적의 공격 피격** | +1 | 기본 |
| **방어 성공** | +2 | 방어 자세 중 피격 |
| **완벽한 방어** | +3 | 타이밍 방어 (후술) |
| **카운터 성공** | +2 | 반격 발동 시 |
| **회피 성공** | +1 | 회피 후 |
| **BRV 피격 (HP 아님)** | +1 | BRV만 받음 |

### 관찰 스택 소실

```yaml
스택 감소:
  - 공격 스킬 사용 시: -2 스택
  - 지원 스킬 사용 시: -1 스택
  - 턴 종료 시: -0 (유지됨!)
  - 전투 종료 시: 전부 초기화

전략적 선택:
  - 공격하면 스택 감소 → 검심 단계 하락
  - 방어/카운터에 집중하면 스택 유지
  - 공격과 방어의 균형이 중요
```

### 검심 3단계별 효과

#### 초심(平心) - 0~4 스택
```yaml
상태: "검의 길에 들어선 초보자"
효과:
  - 반격률: 20%
  - 카운터 데미지: 물리 공격력 100%
  - 특수 능력: 없음
```

#### 무심(無心) - 5~9 스택
```yaml
상태: "검에 몰두하여 잡념이 사라진 상태"
효과:
  - 반격률: 40%
  - 카운터 데미지: 물리 공격력 130%
  - 검압 획득량: +20%
  - 방어력: +15%
  - 특수 능력: "읽기(見切り)" 해금
    → 적의 다음 공격 유형 예측 가능 (물리/마법/BRV/HP)
```

#### 검성(剣聖) - 10+ 스택
```yaml
상태: "검의 도를 깨달은 경지"
효과:
  - 반격률: 70%
  - 카운터 데미지: 물리 공격력 180%
  - 검압 획득량: +50%
  - 방어력: +30%
  - 회피율: +20%
  - 특수 능력:
    1. "완벽한 읽기" - 적의 다음 공격 대상까지 예측
    2. "연속 카운터" - 카운터 후 즉시 추가 공격 가능
    3. "검압 폭발" 해금 - 검압 100 소모로 엄청난 일격
```

## 2. 검압(剣圧) 시스템

> "적의 공격을 견뎌낼 때마다 검의 기운이 모인다."

### 검압 획득 방법

| 행동 | 획득량 | 추가 조건 |
|------|--------|-----------|
| 피격 | 적 공격력의 15% | 최소 5 보장 |
| 방어 성공 | 20 | 방어 자세 중 |
| 회피 성공 | 15 | - |
| 카운터 성공 | 25 | - |
| 적 BRV 5000+ 피격 | +10 보너스 | 강력한 공격 견딤 |
| 검성 상태 피격 | +50% | 검성 단계에서 |

### 검압 소모 스킬

| 스킬명 | 검압 비용 | 효과 | 비고 |
|--------|-----------|------|------|
| **베어넘기기** | 30 | 적 BRV 50% 흡수 → 자신의 BRV로 전환 | 핵심 메커니즘 |
| **검압 베기** | 50 | BRV 3.0 공격 | 순수 화력 |

| **검압 방벽** | 30 | 3턴간 받는 피해 -40% | 생존기 |
| **검압 폭발** | 100 | HP 5.0 공격 + 적 BRV 초기화 | 검성 전용 |

## 3. 패링 시스템 (Parry System) ⚔️ 사무라이 전용

> "한 순간의 판단이 승패를 가른다. 칼날 위를 걸어라."

### 특별한 방어 커맨드: 미키리(見切り)

```yaml
사무라이의 방어는 다릅니다:
  - 일반 방어 커맨드 대신 "미키리(見切り)" 사용
  - 암흑기사의 카운터 시스템을 기반으로 하되 개선
  - 최대 3회까지 공격을 무효화 + 패링 가능

메커니즘:
  - "미키리 카마에(見切り構え)" 스킬 사용
  - 패링 스택 3회 부여 (지속: 3턴)
  - 적의 공격마다 패링 판정 발동
  - 3회 공격까지 무효화 가능
```

### 패링 판정 시스템 (100% 확정)

```yaml
패링 메커니즘:
  - 적 공격 발생 → 자동 패링 (100% 성공)
  - 암흑기사와 동일하게 확정 방어
  - 단, 3회까지 연속 방어 가능 (암흑기사는 1회)

패링 효과:
  - 피해 100% 무효화 (확정)
  - 관찰 스택 +3
  - 검압 +40
  - 강제 반격 발동 (데미지 2.0배)
  - 적 BRV 30% 흡수
  - 패링 스택 -1

스택 소진:
  - 3회 패링 후 자동 해제
  - 턴 종료 시 지속시간 감소
  - 재사용 가능

관찰 스택에 따른 보너스:
  - 초심(0-4): 기본 효과
  - 무심(5-9): 반격 데미지 +30%
  - 검성(10+): 반격 데미지 +80%, 적 BRV 흡수율 +20%
```

### 아군 보호 패링 (義の盾, 기의 방패)

```yaml
메커니즘:
  - "기의 타테(義の盾)" 스킬 사용
  - 대상 아군 지정
  - 다음 적의 공격을 사무라이가 대신 받음
  - 패링 100% 성공 (확정 보호)

효과:
  - 아군 대상 공격을 가로챔
  - 피해 100% 무효화 (확정)
  - 아군 완전 보호
  - 관찰 스택 +4
  - 검압 +50
  - 반격 발동 (데미지 2.5배)

전략:
  - 힐러/마법사 보호
  - 보스의 단일 대상 필살기 차단
  - 팀 생존력 극대화
```

### 3회 패링 활용 전략

```yaml
상황별 활용:

1. 다수전 (적 3마리):
   - 미키리 카마에 사용 (스택 3)
   - 적 3마리 공격 → 3회 패링 (100% 성공)
   - 피해 0 + 관찰 +9 + 검압 +120
   - 무심/검성 진입 가속

2. 보스전 (강력한 연속 공격):
   - 보스의 3연속 공격 패링
   - 확정 방어 + 검압 대량 획득
   - 즉시 반격으로 전환

3. 아군 보호:
   - 힐러 보호용 기의 타테
   - 확정 보호 + 높은 보상
   - 팀 전체 생존력 상승

4. 검성 상태:
   - 패링 반격 데미지 +80%
   - 3회 패링 전부 엄청난 반격
   - 사실상 무적 + 공격
```

## 4. 베어넘기기 시스템 (BRV Steal Counter)

> "적의 힘은 곧 나의 힘이다."

### 핵심 메커니즘

```yaml
베어넘기기:
  조건: 검압 30+ 보유
  효과:
    - 적의 현재 BRV 50% 흡수
    - 흡수한 BRV를 자신의 BRV에 추가
    - 검압 30 소모
    - 관찰 스택 +1

  추가 효과 (검심 단계별):
    - 무심 상태: 흡수 60%
    - 검성 상태: 흡수 80%

  시너지:
    - 적 BRV가 높을수록 효과적
    - BREAK 직전 적에게 사용 시 추가 보너스
    - 반격과 동시에 사용 가능

전략적 활용:
  1. 적이 BRV를 쌓을 때까지 기다림
  2. 방어/카운터로 검압 축적
  3. 적 BRV 최고조일 때 "베어넘기기"
  4. 흡수한 BRV로 HP 공격
  → 적의 공격을 역이용!
```

### 베어넘기기 콤보

| 콤보 | 효과 | 비고 |
|------|------|------|
| **베어넘기기 → HP 공격** | 흡수한 BRV로 즉시 HP 데미지 | 기본 콤보 |
| **반격 → 베어넘기기** | 카운터 후 BRV 추가 흡수 | 적 BRV 급감 |
| **타이밍 방어 → 베어넘기기** | 완벽 방어 후 흡수율 +20% | 고난이도 |
| **베어넘기기 → 검압 베기** | 흡수 후 즉시 대미지 | 폭딜 콤보 |

## 8. 시너지 예시

### 추천 파티 조합

| 조합 | 추천 동료 | 이유 |
|------|-----------|------|
| **탱커 조합** | 기사 + 성기사 + 힐러 | 사무라이가 관찰 쌓는 동안 탱커가 버팀 |
| **고BRV 조합** | 궁수 + 버퍼 + 탱커 | 적 BRV 높일 때 베어넘기기로 흡수 |
| **크리 조합** | 암살자 + 음유시인 | 크리티컬 시너지 + 일도양단 특성 |

### 시너지 직업

- **기사**: 의무로 피해 흡수 → 사무라이가 안전하게 관찰 축적
- **음유시인**: 버프로 사무라이 카운터 데미지 증폭
- **마법사**: 적 BRV 높이기 → 베어넘기기 효율 증가
- **힐러**: 안정적 생존 → 관찰 스택 유지 용이

## 13. 참고: 베어넘기기 상세 메커니즘

### 흡수율 테이블

| 검심 단계 | 기본 흡수 | 타이밍 방어 후 | 반격 자세 중 |
|-----------|----------|----------------|--------------|
| 초심 (0-4) | 50% | 60% | 70% |
| 무심 (5-9) | 60% | 70% | 80% |
| 검성 (10+) | 80% | 90% | 100% |

### 적 BRV별 흡수량 예시

| 적 BRV | 초심 50% | 무심 60% | 검성 80% |
|--------|----------|----------|----------|
| 1000 | 500 | 600 | 800 |
| 3000 | 1500 | 1800 | 2400 |
| 5000 | 2500 | 3000 | 4000 |
| 8000 | 4000 | 4800 | 6400 |
| 10000 | 5000 | 6000 | 8000 |

### 콤보 데미지 예시

```
상황: 적 BRV 8000, 사무라이 검성 상태

1. 베어넘기기 (검압 30 소모)
   - 적 BRV 80% 흡수 = 6400
   - 사무라이 BRV: 0 → 6400
   - 적 BRV: 8000 → 1600

2. 즉시 HP 공격 (발도술)
   - BRV 6400 + 스킬 배율 2.5 = 16000 BRV
   - HP 데미지 배율 1.8 = 28800 HP 데미지!

3. 적 BREAK 발생
   - 적 BRV 0, 스턴 1턴
   - 추가 wound damage

총 효과:
  - HP 데미지: 28800
  - 적 BRV: 8000 → 0
  - 적 무력화 1턴
  → 적의 공격을 완전히 역이용!
```
