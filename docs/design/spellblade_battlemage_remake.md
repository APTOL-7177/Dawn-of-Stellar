# 마검사 & 배틀메이지 리메이크 제안

## 공통 방향
- **하이브리드 정체성 강화**: 물리 검술과 마법을 모두 활용하도록 리소스/쿨 설계.
- **가시성 높은 기믹 UI**: 스택, 회로, 룬 상태가 전투 중 즉시 파악되도록 HUD 슬롯 확보.
- **파티 연계 강화**: 두 직업 모두 아군 행동으로 트리거되는 효과 포함.
- **콘텐츠 역할 분리**: 마검사는 근접-순환형 DPS, 배틀메이지는 룬 설치형 서브 누커/버퍼.

## 마검사 (Spellblade) — "블레이드 서킷" 루프

### 콘셉트 키워드
- **검과 마법이 교차하는 회로**
- 물리 → 마법 → 물리 순환 시 전압(Arc)을 축적해 폭발적인 일격을 가함
- 근거리 포지셔닝, 단일 대상 집중 화력

### 핵심 기믹: 블레이드 서킷 (Blade Circuit)
1. **듀얼 채널**: `Steel Line`(물리 채널)과 `Mana Line`(마법 채널) 두 게이지가 존재.
2. **전환 트리거**: 물리 스킬 사용 시 Steel Line이 충전되고 Mana Line이 과열 상태로 잠시 봉인, 마법 스킬 사용 시 반대.
3. **피드백 스파크**: 다른 채널이 봉인된 상태에서 해당 채널의 스킬을 사용하면 자동으로 `Arc Spark` 발생(추가 하이브리드 피해 + 마나 회수).
4. **레조넌스 패턴**: 연속으로 물리→마법→물리(또는 역순) 성공 시 `Resonance Sigil` 1스택 획득, 최대 3.
5. **미러 엣지 해방**: 시그넷을 소비해 마법/물리 동시 피해, 추가 효과(분쇄, 침묵 등)를 부여하는 마검 전용 결정기 발동.

### 전투 흐름 예시
1. 돌진형 물리 스킬로 Steel Line 충전 + Arc Spark 대기.
2. 즉시 마법 격파 스킬로 Mana Line 충전, Arc Spark 발동(하이브리드 피해 + MP 회복) → Resonance 1스택.
3. 기본 BRV로 Steel Line 재충전 → Resonance 2스택.
4. `Mirror Edge: Overload`로 시그넷 2~3개 소모, 강력한 BRV+HP 동시폭 + 파티 물/마 버프.

### 팀 플레이 역할
- **디버퍼**: Circuit Brand가 물리/마법 방어 모두 깎아 파티 전체 화력 상승.
- **응답형 버스트**: 피드백 스파크와 Mirror Edge를 다른 딜러의 타이밍에 맞춰 폭발시켜 체인.
- **리스크/리턴**: 한 채널을 과충전하면 다른 채널이 봉인되어 슬롯 관리 필요.

### 개발 체크포인트
1. 엔챈트 UI → 듀얼 게이지 및 시그넷 스택으로 대체.
2. Trait 연동: 기존 `mana_conduit` 등을 `Blade Circuit`용 신규 특성으로 맞춤.
3. AI 스크립트: 물/마 번갈아 쓰도록 우선순위 재설정.

## 배틀메이지 (Battle Mage) — "룬 연쇄 폭발" 설계

### 콘셉트 키워드
- **전장 각인사**: 적에게 룬을 새기고 아군이 기폭.
- **연쇄 폭발**: 하나의 룬이 터지면 같은 대상의 모든 룬 동시 폭발.
- **파티 연동**: 배틀메이지가 아닌 다른 아군도 폭발 버튼을 누를 수 있음.

### 핵심 기믹: 룬 공명 필드 (Rune Resonance Field)
1. **룬 각인**: 배틀메이지가 적에게 5원소 룬(화·냉·전·토·비전)을 각인. 대상당 슬롯 4개, 타입 중복 가능.
2. **각인 추적**: 적 개체마다 `carved_runes` 딕셔너리를 유지해 남은 룬 수 표기.
3. **기폭 권한**: 
   - 배틀메이지 본인은 `Detonate Rune` 계열 스킬로 직접 폭발.
   - 파티원은 `Rune Trigger` 보조 버프를 받은 상태에서 자신의 스킬 사용 시 대상의 룬을 터뜨릴 수 있음.
4. **연쇄 규칙**: 하나의 룬이 터지면 **같은 대상**에 남은 룬이 연쇄 폭발하고, 폭발 피해가 전장 전체에 파동처럼 퍼짐. 각 적은 기본 피해를 입고, 피해를 받은 적에게도 룬이 남아 있다면 30% 확률로 그 적의 룬이 추가로 폭발해 2차 광역 피해를 발생시킴(이때도 룬 타입별 2차 효과 적용). 모든 폭발은 0.25초씩 지연되어 "둔탁한 연타" 감각을 주며, 카메라/사운드 연출도 스텝마다 트리거.
5. **확산 연쇄**: 2차 폭발이 성공하면 동일 규칙이 다시 발동해 전장이 연속적인 "룬 폭뢰" 상태로 이어질 수 있음. 연쇄는 1회 파동당 최대 3스텝까지 이어지고, 단계가 올라갈수록 피해량은 70% → 50%로 점감.
6. **룬 공명 게이지**: 동시 폭발하거나 확산 연쇄로 터진 룬 수만큼 `Resonance Gauge` 증가 → 가득 차면 전장의 모든 적 룬을 강제 폭발시키는 `Grand Resonance` 사용 가능.

### 전투 흐름 예시
1. 배틀메이지가 `Rune Carve: Fire`와 `Rune Carve: Lightning`으로 보스에게 룬 2개 부여.
2. 보조 스킬 `Rune Signal`로 파티 전체에 Rune Trigger 부여.
3. 다른 딜러가 자신의 강력한 단일기 사용 → 추가 입력으로 룬 기폭 → 두 룬이 동시에 터지며 화염 화상 + 번개 추가타, Resonance 게이지 +2.
4. 게이지가 가득 차면 배틀메이지가 `Grand Resonance`로 모든 적 룬을 폭발시켜 연쇄 AoE 피해 + 광역 디버프.

### 스킬 라인업 초안

|피니셔|`Grand Resonance`|하이브리드 AoE|게이지 100% 소비|전장 모든 룬 폭발 + 아군 MP 회복|

### 연쇄 폭발 세부 수치 (초안)
- 기본 룬 폭발 피해: BRV 1.2x + HP 0.6x (하이브리드 계산).
- 연쇄 보정: 동일 대상 두 번째 룬 +30%, 세 번째 +50%, 네 번째 +80%.
- **확산 폭발 확률**: 룬 폭발로 피해를 입은 적이 룬을 보유 중이라면 30% 확률로 즉시 추가 폭발 발생(전장 광역 피해, 타입별 2차 효과 유지). 연쇄 단계가 진행될수록 피해 계수는 1단계 100%, 2단계 70%, 3단계 50%, 각 폭발은 0.25초 간격으로 순차 처리.
- 타입별 2차 효과: 화염(화상), 냉기(행동 지연), 번개(BRV 추가 타격), 대지(방깎), 비전(MP 흡수).
- Rune Trigger 창구: 파티원이 기폭 시 **기폭하는 스킬의 속성**에 따라 추가 버프 지급.

### 팀 시너지
1. **다층 디버프**: 연쇄 폭발이 한 대상에게 여러 상태를 한 번에 걸어 탱커/딜러 전부 이득.
2. **체인 플레이**: 룬을 심어두고 파티원 타이밍에 맞춰 폭발 → ATB 조작의 재미.
3. **MP 지원**: Grand Resonance 시 파티 MP/BRV 회복으로 장기전 안정성 제공.

### 구현 체크리스트
1. `carved_runes` 구조 고도화: 목표당 타입·스택·잔여 지속시간을 딕셔너리+큐로 관리.
2. Rune Trigger 입력 UX: 키 바인딩 또는 UI 버튼 필요.
3. 적 AI 대응: 보스가 룬을 감지해 특정 패턴으로 제거/반격하도록 설계해 상호작용 강화.
4. 테스트 케이스: 연쇄 폭발 시 피해 합산, 디버프 중첩, 게이지 증가량을 자동 검증하는 단위 테스트 추가.
