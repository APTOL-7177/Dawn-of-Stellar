# 도적 리메이크 안

## 현재 상태 분석

### 기본 컨셉
- **아키타입**: 속도형 딜러
- **슬로건**: "정정당당? 그건 바보들이나 하는 거지"
- **기믹**: 절도 시스템 (훔치기 + 회피)
- **스피드**: 93 (게임 내 최상위권)

### 현재 문제점

1. **기믹 정체성 충돌**
   - "훔치기"가 핵심인데 전투에서 실용성 부족
   - 회피 보너스가 암살자의 은신과 비슷하게 느껴짐
   - "암살자의 본능" 특성이 암살자와 이름/컨셉 중복

2. **암살자와의 차별화 부족**
   - 둘 다 고속 + 크리티컬 중심
   - 둘 다 회피 후 보너스 구조
   - 도적만의 독창적 플레이 스타일 부재

3. **독 활용 미흡**
   - 독(poison) 스킬이 있지만 기믹과 연계 없음
   - 독이 단순 DoT로만 기능

4. **수동적 플레이**
   - 훔치기 성공 여부가 운에 의존
   - 능동적으로 상황을 만들어가는 느낌 부족

## 리메이크 제안: 농락(Mockery) 시스템

> "도적은 적을 죽이는 게 아니라, 적이 스스로 무너지게 만든다"

### 핵심 철학: 암살자와의 차별화

| 항목 | 암살자 | 도적 (리메이크) |
|------|--------|----------------|
| 전투 스타일 | 은신 → 기습 → 한 방 | 끊임없이 움직이며 적을 갉아먹기 |
| 핵심 자원 | 은신 게이지 | 농락 스택 |
| 딜링 패턴 | 버스트 (한 번에 큰 피해) | 지속 (틱 데미지 + 연속 공격) |
| 생존기 | 은신 (회피율 +80%) | 민첩 (행동 후 추가 회피) |
| 리스크 | 은신 풀리면 취약 | 농락 못 쌓으면 화력 부족 |
| 템포 | 느림 (은신 대기) | 빠름 (끊임없이 행동) |

### 핵심 메카닉: 농락 스택 + 독 시너지

```yaml
기믹:
  name: 농락의 달인
  description: |
    [농락 스택] 적을 갖고 놀아라!
    
    도적이 적에게 행동할 때마다 "농락" 스택 축적.
    농락이 쌓일수록 독이 강해지고, 적은 약해진다.
    
    농락 스택 (대상별, 최대 10):
    - 공격 시: +1
    - 회피 성공 시: +2
    - 독 적중 시: +1
    - 훔치기 성공 시: +3
    
    농락 효과 (적에게 적용):
    - 3 스택: 독 데미지 +50%
    - 5 스택: 명중률 -15%, 독 지속 +1턴
    - 7 스택: 방어력 -20%, 독 틱당 추가 피해
    - 10 스택: "완전 농락" - 독 즉발 + 3턴간 무력화

  독 시너지:
    name: 맹독의 비수
    description: |
      도적의 독은 농락 스택에 비례해 강화된다.
      
      기본 독: 매턴 HP 3% 피해, 3턴 지속
      
      농락 보너스:
      - 3+: 독 데미지 1.5배
      - 5+: 독 지속 +1턴, 적 회복량 -30%
      - 7+: 독 틱마다 BRV 피해 추가
      - 10: 모든 독 스택 즉시 발동 + 3턴 "마비독"
      
      독 중첩:
      - 독은 최대 5중첩 가능
      - 중첩마다 틱 데미지 +50%
      - 5중첩 독 + 10농락 = "치명독" (HP 15%/턴)
```

### 농락 스택 상세

```yaml
농락_스택:
  type: debuff_on_enemy
  max: 10
  decay: 없음 (전투 종료까지 유지)
  
  획득 방법:
    일반 공격: +1
    스킬 공격: +1~2 (스킬별 상이)
    회피 성공: +2
    독 적중: +1 (독 틱마다)
    훔치기 성공: +3
    크리티컬: +1 추가
    
  단계별 효과:
    1~2:
      name: "귀찮은 놈"
      effect: 없음 (농락 시작)
      
    3~4:
      name: "짜증나는 놈"
      effect:
        - 적 독 데미지 +50%
        - 도적 회피율 +10%
        
    5~6:
      name: "미칠 것 같은 놈"
      effect:
        - 적 명중률 -15%
        - 적 독 지속시간 +1턴
        - 적 회복량 -30%
        
    7~9:
      name: "이놈만은 꼭 죽인다"
      effect:
        - 적 방어력 -20%
        - 독 틱마다 BRV 피해 추가
        - 도적 공격 시 농락 +1 추가
        
    10:
      name: "완전 농락"
      effect:
        - 적에게 걸린 모든 독 즉시 발동
        - 3턴간 "마비독": 속도 -50%, 회피 불가
        - 농락 스택 5로 리셋 (유지하며 계속 플레이)
```

### 독 시스템 상세

```yaml
독_시스템:
  name: 비수의 독
  description: 도적의 모든 공격에는 독이 묻어있다
  
  기본 독:
    damage: HP 3%/턴
    duration: 3턴
    max_stack: 5
    
  독 종류:
    기본독:
      name: 약한 독
      source: 일반 공격
      damage: HP 2%/턴
      duration: 2턴
      stackable: true
      
    맹독:
      name: 맹독
      source: 독 바르기, 독침
      damage: HP 4%/턴  
      duration: 3턴
      stackable: true
      special: 회복량 -20%
      
    신경독:
      name: 신경독
      source: 신경독 투척
      damage: HP 3%/턴
      duration: 3턴
      stackable: true
      special: 속도 -10%
      
    마비독:
      name: 마비독
      source: 완전 농락 (10스택)
      damage: HP 5%/턴
      duration: 3턴
      stackable: false
      special: 속도 -50%, 회피 불가, 해제 불가
      
  독_시너지:
    poison_combo:
      name: 복합 중독
      description: 2종류 이상 독 중첩 시 추가 효과
      effects:
        2종류: 독 데미지 +25%
        3종류: 독 지속 +1턴
        4종류: 적 행동 시 독 1틱 추가 발동
```

## 플레이 패턴 예시

### 기본 루프

```
1. 전투 시작
   └─ "독 바르기"로 3턴간 맹독 준비
   
2. 농락 축적 (1~4스택)
   └─ "비수 난무" (3회 타격 = 농락 +3)
   └─ 회피 성공 시 농락 +2 추가
   
3. 독 강화 구간 (5~6스택)
   └─ 적 명중률 -15%, 독 지속 +1턴
   └─ "신경독 투척"으로 속도 디버프
   └─ 적이 도적 맞추기 어려워짐
   
4. 무력화 구간 (7~9스택)
   └─ 적 방어 -20%, 독이 BRV도 깎음
   └─ "기습"으로 확정 크리티컬
   └─ "조롱"으로 어그로 유도 + 회피로 농락 추가
   
5. 피니시 (10스택)
   └─ "완전한 무력화" 발동
   └─ 모든 독 즉시 터짐 + 3턴 마비독
   └─ 적은 속도 -50%, 회피 불가 상태
   └─ 농락 5로 리셋 → 다시 루프
```

### 보스전 전략

```
단일 보스:
  - 계속 농락 쌓으며 독 중첩
  - 10스택 도달 → 독 폭발 → 리셋 → 반복
  - 궁극기로 한 번에 농락 6 + 독 전종류 부여
  
다수 잡몹:
  - 한 놈에게 농락 5 축적 후 "연쇄 감염"
  - 전체에 독 퍼뜨린 후 "독 폭발"
  - 정리 후 다음 타겟
  
대 회피 보스:
  - "그림자 밟기"로 회피 불가 부여
  - "신경독"으로 속도 감소
  - 농락 높으면 명중률 디버프 효과
```

## 암살자 vs 도적 비교표

| 상황 | 암살자 | 도적 |
|------|--------|------|
| 전투 시작 | 은신 상태, 기회 노림 | 독 바르기, 농락 시작 |
| 첫 공격 | 은신 해제 대신 +150% 데미지 | 독 + 농락 1~3 |
| 중반 | 재은신 대기 (2~3턴) | 계속 공격하며 농락 축적 |
| 화력 피크 | 은신 첫 타격 | 농락 10 + 독 폭발 |
| 위기 대응 | 긴급 은신 | 연막탄 + 회피로 농락 |
| 딜링 타입 | 폭발적 버스트 | 지속적 DoT + 난타 |
| 리소스 관리 | 은신 게이지 | 농락 스택 (적 단위) |
| 다수전 | 1명씩 암살 | 독 전파 + 광역 무력화 |

| 조합 | 역할 분담 | 시너지 |

## 밸런스 고려사항

### 수치 조정

- **농락 획득 속도**: 평균 2~3/행동, 4~5턴에 10 도달 목표
- **독 데미지**: 기본 2~4%/턴, 5중첩 시 10~15%/턴
- **마비독**: 3턴 고정, 해제 불가 (궁극급 CC)
- **완전 농락 리셋**: 10→5로 리셋 (0이 아닌 5로 유지)

### 카운터 플레이

- **독 면역 보스**: 농락 디버프는 적용되지만 독 데미지 무효
- **정화 스킬**: 독 해제 시 농락도 2 감소
- **빠른 적**: 도적보다 빠르면 농락 쌓기 전에 처치 시도
- **광역기**: 회피 불가 광역으로 도적 견제

## 결론

리메이크된 도적은 **"빠른 속도로 적을 끊임없이 괴롭히며 독으로 갉아먹는"** 플레이 스타일을 가집니다.

**암살자와의 핵심 차별점:**
- 암살자: 은신 → 대기 → 한 방 (버스트)
- 도적: 계속 움직임 → 농락 축적 → 독 폭발 (지속 딜링)

**재미 요소:**
- 농락 스택이 쌓일수록 적이 점점 약해지는 쾌감
- 여러 종류의 독을 조합하는 전략
- 10스택 "완전 농락" 달성 시 폭발적 피니시
- 회피하면서 공격하는 민첩한 플레이
