# 도적 스킬 라틴어 명명안

## 📜 개요

기존의 유치한 스킬 이름을 **라틴어 기반**으로 변경하여 고풍스럽고 세련된 느낌을 부여합니다.
라틴어 원문과 한글 표기, 의미를 함께 표시합니다.

## 🎨 스타일 가이드

### 발음 표기 규칙
- **c**: [ㅋ] 발음 (Celer → 켈레르)
- **ti**: [티] 발음 (Punctio → 푼크티오, 시오 아님)
- **u**: [우] 발음 (Umbra → 움브라)
- **v**: [ㅂ/ㅜ] 발음 (Venenum → 베네눔, Velum → 벨룸)
- **ae**: [애] 발음

### 조합 원칙
1. **명사 + 명사**: 소유격으로 연결 (Mortis Signum)
2. **형용사 + 명사**: 형용사가 앞에 (Celer Punctio)
3. **단독 명사**: 그 자체로 의미 전달 (Sicarius, Furtum)

### UI 표시
- **기본**: 라틴어 + 한글 병기
  - 예: `Umbra Ictus (움브라 익투스)`
- **간략**: 라틴어만 또는 한글만
  - 예: `Umbra Ictus` 또는 `움브라 익투스`
- **툴팁**: 한글 의미 추가
  - 예: `Umbra Ictus (움브라 익투스) - 그림자 타격`

## 🔨 적용 방법

### 1. YAML 파일 업데이트
```yaml
skills:
  - rogue_umbra_ictus      # Umbra Ictus (움브라 익투스)
  - rogue_nox_cadens       # Nox Cadens (녹스 카덴스)
  - celer_punctio          # Celer Punctio (켈레르 푼크티오)
  - ludibrium              # Ludibrium (루디브리움)
  - fumus_velum            # Fumus Velum (푸무스 벨룸)
  - dorsum_vulnus          # Dorsum Vulnus (도르숨 불누스)
  - furtum                 # Furtum (푸르툼)
  - venenum_illitus        # Venenum Illitus (베네눔 일리투스)
  - sicarius               # Sicarius (시카리우스)
  - umbra_incursio         # Umbra Incursio (움브라 인쿠르시오)
```

### 2. 스킬 생성 코드 업데이트
```python
umbra_ictus = Skill(
    "rogue_umbra_ictus",
    "Umbra Ictus",  # 라틴어 이름
    "그림자처럼 빠른 기본 공격. 농락 +1."
)
```

### 3. 한글 부제 추가 (선택)
```python
umbra_ictus.display_name = "Umbra Ictus (움브라 익투스)"
umbra_ictus.subtitle = "그림자 타격"
```

## 📚 라틴어 어휘 사전

### 공격 관련
- **Ictus** (익투스): 타격
- **Impetus** (임페투스): 공격, 돌진
- **Vulnus** (불누스): 상처
- **Punctio** (푼크티오): 찌르기, 관통
- **Incursio** (인쿠르시오): 습격, 침입

### 그림자/어둠
- **Umbra** (움브라): 그림자
- **Nox** (녹스): 밤
- **Tenebrae** (테네브라이): 어둠

### 독
- **Venenum** (베네눔): 독
- **Toxicum** (톡시쿰): 독소
- **Pestis** (페스티스): 역병
- **Letale** (레탈레): 치명적인

### 기만/회피
- **Deceptio** (데켑티오): 기만
- **Elusio** (엘루시오): 회피
- **Ludibrium** (루디브리움): 조롱
- **Irrisio** (이리시오): 비웃음

### 죽음
- **Mortis** (모르티스): 죽음의 (소유격)
- **Mors** (모르스): 죽음
- **Sicarius** (시카리우스): 암살자

### 기타
- **Furtum** (푸르툼): 절도
- **Praeda** (프라이다): 약탈, 전리품
- **Velum** (벨룸): 장막, 베일
- **Signum** (시그눔): 표시, 징표
