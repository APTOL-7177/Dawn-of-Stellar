# 리메이크 직업 가이드 (2025-12)

## 개요
6개 직업의 기믹 시스템 전면 개편. 기존 단순 게이지 → 전략적 선택 중심.

---

## 1. 정령술사 (Elementalist)
**기믹**: `elemental_spirits` - 정령 전환 시스템

### 핵심 메커니즘
- **정령 4종**: 화염/물/바람/대지
- **공명**: 2정령 조합 시 강력한 시너지 발동
- **융합 스킬**: 공명 상태에서만 사용 가능한 궁극 스킬

### 공명 조합 (6종)
| 조합 | 이름 | 효과 |
|------|------|------|
| 화+수 | 증기 공명 | 마공 +25%, 관통 +15% |
| 화+풍 | 폭풍염 | 피해 +30%, 광역화 |
| 화+지 | 용암 | 지속 피해, 방어무시 |
| 수+풍 | 빙결폭풍 | 빙결 확률 +50% |
| 수+지 | 생명 | 힐 +40%, 정화 |
| 풍+지 | 사막폭풍 | 명중↓, 속도↓ |

### 밸런스 평가
- **강점**: 상황별 대응력, 융합 스킬 폭발력
- **약점**: 정령 전환에 행동 소모, 초반 빌드업 필요
- **난이도**: ★★★☆☆

---

## 2. 검투사 (Gladiator)
**기믹**: `crowd_cheer` - 콜로세움 쇼타임

### 핵심 메커니즘
- **환호 게이지** (0~100): 관중의 환호
- **5단계 시스템**: 무명 → 도전자 → 떠오르는 별 → 챔피언 → 전설
- **관중 요구**: 특정 행동 수행 시 보너스

### 단계별 효과
| 환호 | 단계 | 공격 보너스 |
|------|------|-------------|
| 0~19 | 무명 | 없음 |
| 20~39 | 도전자 | +5% |
| 40~69 | 떠오르는 별 | +15%, 크리 +10% |
| 70~89 | 챔피언 | +25%, 크리 +20%, 광역화 |
| 90~100 | 전설 | +40%, 크리 +30%, 궁극기 강화 |

### 관중 요구 시스템
- **마무리 일격**: 적 처치로 충족
- **반격**: 회피 후 공격
- **위기 생존**: HP 30% 이하에서 생존
- **연속 콤보**: 3연속 공격

### 밸런스 평가
- **강점**: 장기전 압도적 딜, 관중 요구 충족 시 급상승
- **약점**: 미충족 시 환호 감소, 초반 약함
- **난이도**: ★★☆☆☆

---

## 3. 해커 (Hacker)
**기믹**: `intrusion_system` - 침투 시스템

### 핵심 메커니즘
- **RAM** (0~8): 스킬 사용 자원 (+2/턴 회복)
- **침투 게이지** (적 단위, 0~100%): 누적 시 디버프
- **오버클럭**: 일시적 강화 모드

### 침투 단계
| 침투 | 효과 |
|------|------|
| 25% | 방어 -10% |
| 50% | 방어 -20%, 속도 -10% |
| 75% | 방어 -30%, 스킬 봉인 |
| 100% | **장악** - 조종/즉사 가능 |

### 장악 스킬 (100% 필요)
- **시스템 장악**: 적 1턴 조종
- **데이터 삭제**: 버프 전체 제거
- **강제 종료**: 즉시 처형 (보스 불가)
- **바이러스 확산**: 전체 적 침투 +25%

### 밸런스 평가
- **강점**: 유틸리티, 장악 시 전투 지배
- **약점**: RAM 관리 필수, 보스전 장악 제한
- **난이도**: ★★★★☆

---

## 4. 성기사 (Paladin)
**기믹**: `oath_system` - 서약 시스템

### 핵심 메커니즘
- **서약 3종**: 전투 시작 시 1개 선택
- **신앙 게이지** (0~100): 서약 준수로 축적
- **기적 스킬**: 신앙 임계값 도달 시 해금

### 서약 종류
| 서약 | 효과 | 금지 행동 | 신앙 획득 |
|------|------|-----------|-----------|
| 인내 | 방어 +20% | 연속 공격 | 피격 시 +3 |
| 순결 | 디버프 면역 | 암흑 스킬 | 정화 시 +5 |
| 자비 | 힐 +30% | 적 처치 | 힐 시 +5 |

### 기적 스킬
| 신앙 | 스킬 | 효과 |
|------|------|------|
| 25+ | 작은 기적 | HP 50% 회복 |
| 50+ | 보호의 기적 | 아군 무적 1턴 |
| 75+ | 치유의 기적 | 전체 HP 50% + 정화 |
| 100 | 신의 심판/은총 | 궁극 기적 (서약에 따라) |

### 밸런스 평가
- **강점**: 안정성, 위기 대응력
- **약점**: 서약 위반 시 신앙 손실, 유연성 부족
- **난이도**: ★★★☆☆

---

## 5. 신관 (Priest)
**기믹**: `oracle_system` - 신탁 시스템

### 핵심 메커니즘
- **신탁**: 라운드마다 무작위 미션 부여
- **신앙 게이지** (0~100): 신탁 충족으로 획득
- **연속 충족 보너스**: 콤보 시 추가 효과

### 신탁 종류
| 신탁 | 조건 | 보상 |
|------|------|------|
| 치유의 신탁 | 아군 회복 | 신앙 +20 |
| 보호의 신탁 | 아군 버프 | 신앙 +15 |
| 정화의 신탁 | 디버프 제거 | 신앙 +20 |
| 심판의 신탁 | 언데드/악마 공격 | 신앙 +25 |

### 연속 충족 보너스
| 연속 | 보너스 |
|------|--------|
| 2회 | 신앙 +10 |
| 3회 | 스킬 효과 +20% |
| 4회 | 자동 기적 발동 |

### 밸런스 평가
- **강점**: 힐러 최강, 콤보 시 폭발적 효율
- **약점**: 신탁 RNG 의존, 공격력 낮음
- **난이도**: ★★☆☆☆

---

## 6. 도적 (Rogue)
**기믹**: `mockery_system` - 농락 시스템

### 핵심 메커니즘
- **농락 게이지** (적 단위, 0~10): 회피/조롱으로 축적
- **독 시스템**: 3단계 중첩 (기본→맹독→치명독)
- **은신**: 3연속 회피 또는 스킬로 돌입

### 농락 효과
| 농락 | 효과 |
|------|------|
| 7+ | 적 명중 -30%, 받는 피해 +20% |
| 10 | **굴욕** - 다음 공격 필중 + 필크리 |

### 독 시스템
| 단계 | 효과 | 중첩 |
|------|------|------|
| 기본 독 | HP -5%/턴 | 1 |
| 맹독 | HP -10%/턴, 회복 불가 | 2 |
| 치명독 | HP -15%/턴, 받는 피해 +20% | 3 |

### 은신 시스템
- **돌입 조건**: 3연속 회피 또는 연막탄
- **은신 효과**: 다음 공격 피해 2.5배
- **해제**: 공격 사용 시

### 밸런스 평가
- **강점**: 단일 타겟 최강, 회피 특화
- **약점**: 광역 약함, 농락 축적 시간 필요
- **난이도**: ★★★☆☆

## 직업 간 밸런스 비교

### DPS 순위 (단일 타겟)
1. **도적** - 은신+굴욕 콤보 시 최강
2. **검투사** - 전설 단계 도달 시
3. **해커** - 장악 + 바이러스 시
4. **정령술사** - 융합 스킬 연계 시
5. **성기사** - 공격 특화 아님
6. **신관** - 힐러 (공격 최하위)

### 유틸리티 순위
1. **해커** - CC, 디버프, 조종
2. **신관** - 힐, 버프, 정화
3. **성기사** - 보호, 기적
4. **정령술사** - 속성 대응
5. **도적** - 독, 디버프
6. **검투사** - 순수 딜러

### 생존력 순위
1. **성기사** - 서약 + 기적
2. **검투사** - 높은 HP, 방어
3. **도적** - 회피 특화
4. **신관** - 자가 힐
5. **정령술사** - 중간
6. **해커** - 최하위 (유리 대포)

## 구현 로드맵 (엔진 반영용)
> 현황: 리메이크 기획은 완료됐으나 엔진/데이터 미반영. 아래 체크리스트대로 단계별 구현.

### 공통 선행 작업
- `src/character/character.py`: 직업별 신규 기믹 필드 추가(기본값/최대값 포함).
- `src/character/gimmick_updater.py`: 턴 시작/종료/피격/처치/치유 이벤트 훅에 신규 기믹 처리 분기 추가.
- `src/character/skills/skill.py`/`skill_manager.py`: 스킬 실행 컨텍스트에 기믹 상태 전달, 조건 충족 시 게이지 변동 지원.
- 테스트: `tests/test_remake_gimmicks.py`에 직업별 기믹 단위 테스트 추가.

### 1) 성기사 (Paladin) - 서약/신앙 시스템
- 참고: `docs/design/paladin_remake.md`
- 캐릭터 필드: `oath`(enum), `faith`(0~100), `violations`, `current_oath_effects`.
- 로직:
  - 전투 시작/`서약 선언` 스킬 사용 시 서약 선택 → `faith` 50% 감소 후 변경.
  - 서약 유지 조건 검사: 턴 종료 시/행동 시 위반 여부 확인, 위반 시 신앙 감소 + 일시 디버프.
  - 신앙 획득: 서약별 조건 충족 시 `faith += X`, 최대 100.
  - 기적 스킬: 신앙 임계값(25/50/75/100) 도달 시 스킬 언락/강화. 스킬 메타데이터로 요구 신앙 체크.
- 데이터: 신규 기적 스킬을 YAML에 추가(조건부 시전 가능, `metadata.required_faith`).

### 2) 검투사 (Gladiator) - 관중 요구/쇼타임
- 참고: `docs/design/gladiator_remake.md`
- 캐릭터 필드: `cheer`(0~100), `crowd_demand`(현재 요구 목록), `demand_progress`, `showtime_stage`.
- 로직:
  - 라운드 시작 시 요구 1~2개 추출 → HUD 표기.
  - 요구 충족/실패 처리: 성공 시 환호 + 보너스 버프/특수 효과, 실패 시 환호 감소 + 야유 디버프.
  - 환호 단계에 따른 상시 보정(공/크리/반격/회피 등) 적용.
  - 환호 100 → `그랜드 피날레` 해금/강화.
- 데이터: 요구 달성/실패에 따른 버프를 메타데이터 테이블로 정의(`crowd_demands`).

### 3) 정령술사 (Elementalist) - 정령 공명/융합
- 참고: `docs/design/elementalist_remake.md`
- 캐릭터 필드: `spirit_fire/water/wind/earth`, `max_spirits`, `fusion_state`.
- 로직:
  - 정령 소환/해제 스킬로 정령 상태 관리(최대 2~3기).
  - 공명 체크: 정령 2기 보유 시 조합 식별 → 공명 버프 적용.
  - 융합 스킬: `metadata.requires`로 정령 종류 확인 후 사용 가능; 사용 시 공명/정령 소모 여부 처리.
- 데이터: 공명/융합 스킬 YAML 정의 업데이트(조건부 사용, 버프/광역화/도트 등).

### 4) 해커 (Hacker) - 침투/RAM/장악
- 참고: `docs/design/hacker_remake.md`
- 캐릭터 필드: `ram`(0~8), `intrusion` per target(0~100), `overclock_turns`.
- 로직:
  - 턴당 RAM 자동 회복(+2), 최대 8. 스킬 비용에서 RAM 우선 사용.
  - 침투 스택: 대상별로 공격/디버프 시 누적, 25/50/75/100 구간 보너스 처리.
  - 100% 장악 시 전용 스킬(조종/삭제/즉사/확산) 사용 가능. 보스 저항 처리.
  - 오버클럭: 제한 턴수 동안 스킬 위력/침투 증가, 종료 시 RAM 과열 페널티.
- 데이터: 각 침투 단계/오버클럭 효과를 메타데이터 테이블로 선언.

### 5) 신관 (Priest) - 신탁/기적 콤보
- 참고: `docs/design/priest_remake.md`
- 캐릭터 필드: `oracle_current`, `oracle_chain`, `faith`(힐러용), `oracle_history`.
- 로직:
  - 라운드 시작 시 신탁 배정(랜덤/가중치), HUD 표기.
  - 신탁 충족 시 신앙 획득 + 연속 콤보 카운트; 실패 시 리셋.
  - 콤보 보너스 단계별 효과 적용(신앙 추가/스킬 증폭/자동 기적).
  - 기적 스킬: 신앙 임계값에 따라 자동 발동 또는 수동 해금.
- 데이터: 신탁 조건/보상 테이블, 기적 스킬 YAML.

### 6) 도적 (Rogue) - 농락/독/은신
- 참고: `docs/design/rogue_remake.md`
- 캐릭터 필드: `mockery` per target(0~10), `poison_tier` per target, `stealth_active`, `stealth_turns`.
- 로직:
  - 농락 스택 획득 트리거: 공격/회피/독 적중/훔치기/크리티컬.
  - 농락 단계별 효과 적용(명중↓, 피해증가, 필중/필크리 등).
  - 독 시스템: 기본/맹독/치명독 3단계, 중첩 시 추가 효과(회복 불가/받는 피해 증가).
  - 은신: 조건 충족 시 진입, 다음 공격 2.5배 + 필중, 공격 시 해제.
- 데이터: 농락/독/은신 상태를 상태이상 또는 메타데이터 버프로 모델링.

### 구현 순서 제안
1. Paladin/Gladiator: 방어/딜 커버리지 확보 + 쇼케이스 효과 커서 먼저 적용.
2. Hacker/Rogue: 상태/스택형 기믹이 겹쳐 테스트 케이스 공유 가능.
3. Priest/Elementalist: RNG 미션/정령 조합 등 UI 의존도 높으므로 마지막에 통합.
