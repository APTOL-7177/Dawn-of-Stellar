### 2. ✅ 검심 반격 시스템
- 피격 시 자동 반격 (피해 감소 + BRV 반사)
- 3단계 시스템:
  - **초심(0-4)**: 피해 10%↓, BRV 30% 반사
  - **무심(5-9)**: 피해 20%↓, BRV 50% 반사
  - **검성(10+)**: 피해 35%↓, BRV 80% 반사
- 관찰 스택 최대: 15 (검성 진입: 10+)
- 파일: `src/character/character.py` (1240-1253라인)

### 3. ✅ BRV 흡수 스킬 (미키리)
- 검압 30 소모
- 관찰 단계별 흡수율:
  - 초심: 50%
  - 무심: 60%
  - 검성: 80%
- 특성(미키리의 달인) 적용 시 +10%
- 파일: `src/character/gimmick_updater.py` (5640-5700라인)

### 4. ✅ 요미 스킬 - 적 행동 예측
- **턴 소모 없음** (instant=True)
- 무심(5+) 상태에서만 사용 가능
- 예측 정보:
  - 적의 다음 행동 타입 (HP 공격, BRV 공격, 스킬 사용 등)
  - 적의 현재 ATB 게이지 (%)
  - ATB 최대값 및 퍼센티지
  - 예측 지속: 2턴
- 파일: `src/character/gimmick_updater.py` (5702-5757라인)

### 5. ✅ 패링형 궁극기
- **텐치쥬잔**: 평시 HP 2.5배 → 패링 중/성공 후 3턴 내 사용 시 HP 6.0배 + 적 BRV 초기화
- **무료타이가**: 평시 HP 2.0배 (전체) → 패링 강화 시 HP 5.0배 + 무적 3턴
- 파일: `src/character/skills/job_skills/samurai_skills.py` (167-216라인)

### 6. ✅ 특성 효과 (5개)
- `kenshin_growth`: 검심의 성장 (관찰 스택에 따른 반격 강화)
- `meditation`: 참선 (패링 중 피격 시 HP/MP 10% 회복)
- `iaijutsu`: 발도술 (선제 공격 시 크리티컬 확정 + 데미지 2배)
- `iron_will`: 강철 의지 (HP 1로 생존, 전투당 1회)
- `brv_absorb_master`: 미키리의 달인 (BRV 흡수 +10%)
- 파일: `src/character/gimmick_trait_effects.py` (866-935라인)

## 핵심 메커니즘

### 검심 사이클
```
피격 → 반격 (피해 감소 + BRV 반사) → 관찰/검압 획득 →
       ↓
단계 상승 (초심 → 무심 → 검성) →
       ↓
강력한 반격 + 패링 성공률 향상 →
       ↓
패링 성공 → 카운터 데미지 2.5배 →
       ↓
궁극기 강화 조건 충족 → 최대 피해
```

### 관찰 스택 관리
- **획득**: 피격 시 +1~3, 패링 성공 시 +3
- **소모**: 공격 스킬 사용 시 -2
- **감소**: 턴 종료 시 -1
- **최대**: 15 (검성 진입: 10+)

### 검압 게이지 관리
- **획득**: 피격 시 +5~15, 패링 성공 시 +40
- **소모**: 검압 스킬 사용 (미키리 30, 켄아츠잔 50, 궁극기 60/100)
- **최대**: 100

## 플레이 가이드

### 초반 전략
1. **미키리 카마에** 사용하여 패링 대기
2. 피격 시 자동 반격으로 관찰 스택 축적
3. 관찰 5 도달 시 **무심** 진입 → 반격 강화

### 중반 전략
1. **요미** 스킬로 적 행동 예측 (ATB 확인)
2. 적의 공격 타이밍에 맞춰 **미키리 카마에** 사용
3. 패링 성공 → 카운터 2.5배 데미지

### 후반 전략
1. 관찰 10 도달 시 **검성** 진입 → 최대 반격력
2. 검압 60 이상 모으면 **텐치쥬잔** 사용 가능
3. 패링 성공 후 3턴 내 궁극기 사용 → 최대 피해 (HP 6.0배)
