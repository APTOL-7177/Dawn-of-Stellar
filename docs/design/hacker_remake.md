# 해커 리메이크 안
**작성일**: 2025-12-03
**버전**: 1.0

---

## 현재 상태 분석

### 기본 컨셉
- **아키타입**: 디버프 특화
- **슬로건**: "시스템을 지배하는 자가 전장을 지배한다"
- **기믹**: 멀티스레드 시스템 (최대 3개 프로그램 동시 실행)

### 현재 문제점

1. **수동적 프로그램 관리**
   - 프로그램을 켜두기만 하면 되는 단순한 구조
   - 전략적 의사결정 포인트 부족
   - MP만 있으면 무한정 유지 가능

2. **적과의 상호작용 부족**
   - 프로그램이 일방적으로 디버프만 거는 구조
   - 적의 특성이나 상태를 활용하지 않음
   - "해킹"이라는 테마의 재미 요소 미반영

3. **리스크-리워드 부재**
   - 프로그램 실행에 리스크가 없음
   - 오버클러킹 등의 특성이 있지만 체감 약함

4. **스킬 다양성 부족**
   - 프로그램 ON/OFF 스킬 위주
   - 능동적인 해킹 공격 스킬 부족

## 리메이크 제안: 침투 시스템 (Intrusion System)

> "해커는 적의 시스템에 침투하여, 내부에서부터 무너뜨린다"

### 핵심 컨셉

**적을 "해킹"하여 침투 게이지를 쌓고, 완전 침투 시 강력한 효과 발동**

- 각 적에게 개별 **침투 게이지 (0~100)** 존재
- 해킹 스킬 사용 시 침투 게이지 상승
- 게이지 단계별로 점점 강해지는 디버프
- **100% 침투 완료 시** 적을 완전히 장악 (원턴 조종, 데이터 탈취 등)

```yaml
기믹:
  name: 시스템 침투
  description: |
    적에게 해킹 공격 시 "침투 게이지" 축적.
    침투 단계에 따라 적에게 누적 디버프.
    침투 완료 시 "완전 침투"로 적 시스템 장악.
    
  필요 침투량 공식:
    필요량 = (적 최대 HP / 해커 마법력) × 2
    
    예시:
      - 적 HP 1000, 마공 100 → 필요량 20
      - 적 HP 2000, 마공 100 → 필요량 40
      - 적 HP 2000, 마공 200 → 필요량 20
      - 보스 HP 5000, 마공 150 → 필요량 67
    
    최소값: 15, 최대값: 100 (극단적 수치 방지)
    
  침투 단계 (필요량 대비 %):
    - 0~24%: 스캔 중 (적 정보 일부 공개)
    - 25~49%: 백도어 설치 (방어 -15%)
    - 50~74%: 권한 탈취 (공격/방어 -20%, 속도 -15%)
    - 75~99%: 루트 접근 (공격/방어/속도 -30%, 스킬 쿨다운 +1)
    - 100%: 완전 침투 (장악 스킬 해금)
    
  장악 효과 (100% 도달 시 선택):
    - "시스템 크래시": 마공 350% 피해 + BRV 전파괴 + 1턴 기절
    - "데이터 와이프": 적 버프 전해제 + 3턴 버프 불가 + 마공 150% 피해
    - "바이러스 폭발": 축적한 침투량 × 1%의 고정 피해 (방무)
    - "메모리 덤프": 아군 전체 HP 20% 회복 + MP 15 회복
```

## 상세 기믹: 자원 관리 시스템

### 해커 전용 자원: RAM

> "복잡한 해킹일수록 더 많은 연산 자원이 필요하다"

```yaml
RAM 시스템:
  최대치: 8 GB
  회복: 매턴 +2 GB
  
  사용처:
    - 프로그램 실행: 1~3 GB (유지 비용 없음)
    - 해킹 스킬: 0~2 GB
    - 장악 스킬: 4 GB
    
  오버클럭 모드:
    조건: RAM 8 GB 상태에서 "오버클럭" 발동
    효과: 
      - 3턴간 RAM 최대치 12 GB로 확장
      - 침투 속도 +50%
      - 매턴 HP -5% (과열)
    종료 후: 1턴간 RAM 회복 불가 (쿨다운)
```

### 프로그램 시스템 개편

> "프로그램은 RAM을 소모하여 즉시 효과를 발휘하고 사라진다"

```yaml
기존: 프로그램 상시 가동 (MP 지속 소모)
변경: 프로그램 1회 실행 (RAM 소모, 즉시 효과)

프로그램 목록:
  스캐너:
    RAM: 1 GB
    효과: 단일 적 침투 +15, 약점 공개
    
  트로이 목마:
    RAM: 2 GB
    효과: 단일 적 침투 +25, 다음 해킹 스킬 효과 +30%
    
  웜 바이러스:
    RAM: 2 GB
    효과: 전체 적 침투 +10, 침투 50%+ 적에게 확산 +5 추가
    
  랜섬웨어:
    RAM: 3 GB
    효과: 단일 적 침투 +20, 2턴간 "암호화" (스킬 사용 시 추가 MP 소모)
    
  키로거:
    RAM: 1 GB
    효과: 단일 적 침투 +10, 3턴간 적 행동 미리보기 (다음 스킬 표시)
    
  루트킷:
    RAM: 3 GB
    효과: 단일 적 침투 +30, 침투 게이지 감소 불가 (3턴)
```

## 침투 단계별 상세 효과

### 0~24%: 스캔 중

```yaml
효과:
  - 적 HP/MP 수치 공개
  - 적 약점 속성 표시
  - "스캔됨" 표시 (시각적)
  
보너스:
  - 해커의 해당 적 대상 명중 +10%
```

### 25~49%: 백도어 설치

```yaml
효과:
  - 이전 단계 효과 유지
  - 방어력 -15%
  - 적 버프 지속시간 -1턴
  
보너스:
  - 해커의 침투 스킬 효과 +10%
```

### 50~74%: 권한 탈취

```yaml
효과:
  - 이전 단계 효과 유지
  - 공격력/방어력 -20%
  - 속도 -15%
  - 적 회피 -20%
  
보너스:
  - 파티 전원의 해당 적 대상 크리티컬 +10%
```

### 75~99%: 루트 접근

```yaml
효과:
  - 이전 단계 효과 유지
  - 공격력/방어력/속도 -30%
  - 스킬 쿨다운 +1턴
  - 적 치유 효과 -50%
  
보너스:
  - 해당 적에게 주는 피해 +20% (파티 전원)
  - "완전 침투" 예고 표시
```

### 100%: 완전 침투

```yaml
효과:
  - 모든 디버프 유지
  - "장악" 스킬 사용 가능
  - 사용 후 침투 게이지 0으로 리셋
  - 동일 적 재침투 시 저항: 침투 속도 -25%
```

## 장악 스킬 (침투 100% 전용)

### 1. 시스템 크래시

```yaml
RAM: 4 GB
효과:
  - 마법력 350% 피해
  - 적 BRV 전부 파괴
  - 1턴 기절 (보스 포함)
  
추천 상황:
  - 위험한 적 빠르게 처치
  - BRV 높은 적 상대
```

### 2. 데이터 와이프

```yaml
RAM: 4 GB
효과:
  - 적의 모든 버프 제거
  - 3턴간 "시스템 손상": 버프 획득 불가
  - 마법력 150% 추가 피해
  
추천 상황:
  - 적이 강력한 버프를 받았을 때
  - 지속적으로 버프 거는 적 상대
```

### 3. 바이러스 폭발

```yaml
RAM: 4 GB
효과:
  - 축적한 침투량 × 10 고정 피해 (방어 무시)
  - 예: 침투 40 달성 → 400 고정 피해
  - 예: 침투 80 달성 → 800 고정 피해
  - 인접 적에게 50% 피해 전파
  
추천 상황:
  - HP 높은 적 (침투량도 높음)
  - 보스전 피니셔
```

### 4. 메모리 덤프

```yaml
RAM: 4 GB
효과:
  - 아군 전체 HP 20% 회복
  - 아군 전체 MP 15 회복
  - 해커 RAM 즉시 +4 GB
  
추천 상황:
  - 파티 체력/마나 부족 시
  - 장기전에서 자원 회복
```

## 궁극기 & 팀워크

### 궁극기: 시스템 전면 장악

```yaml
MP: 40
RAM: 6
조건: 적 1명 이상 침투 50%+

효과:
  1. 전체 적 침투 +40
  2. 침투 100% 달성한 적 모두에게 "강제 셧다운" (1턴 행동불능)
  3. 해커 3턴간 "관리자 권한":
     - 모든 침투 스킬 효과 2배
     - RAM 매턴 +4 회복
     - 장악 스킬 RAM 비용 -2
```

### 팀워크: 분산 해킹 네트워크

```yaml
게이지: 100%

효과:
  1. 파티 전원 "해킹 노드" 버프 (3턴):
     - 공격 시 추가 침투 +5 (해커 지정 대상에게)
     - 공격력 +10%
  2. 전체 적 침투 +25
  3. 침투 75%+ 적 전원에게 "시스템 불안정" (2턴):
     - 스킬 30% 확률 실패
     - 실패 시 자기 피해 (현재 HP 10%)
```

## 운용 전략

### 침투 우선순위

```
전투 시작
  ↓
1순위 대상 선정 (위협적인 적)
  ↓
스캐너/트로이 목마로 빠르게 침투 축적
  ↓
50% 도달 → 권한 탈취 디버프로 파티 화력 집중
  ↓
100% 도달 → 상황에 맞는 장악 스킬 선택
  ↓
리셋 후 차순위 대상으로 전환
```

### 상황별 장악 스킬 선택

| 상황 | 추천 장악 스킬 | 이유 |
|------|---------------|------|
| 즉시 처치 필요 | 시스템 크래시 | 고데미지 + 기절로 마무리 |
| 적 버프 많음 | 데이터 와이프 | 버프 제거 + 획득 봉쇄 |
| 고HP 적/보스 | 바이러스 폭발 | 침투량 비례 고정피해 |
| 파티 자원 부족 | 메모리 덤프 | HP/MP 회복으로 지속전 |

### 추천 파티 조합

| 조합 | 시너지 |
|------|--------|
| 해커 + 딜러 2 + 힐러 | 침투 디버프로 딜러 화력 극대화 |
| 해커 + 암살자 + 서포터 | 암살자 집중 타겟, 해커가 디버프 |
| 해커 + 해커 + 딜러 2 | 쌍해커 침투 가속, 빠른 장악 |

## 밸런스 고려사항

### 침투 속도 조정

- 일반 적: 3~4턴 내 100% 도달 가능하도록
- 보스: 5~6턴 내 100% 도달
- 보스 저항: 침투 효과 -30%

### 장악 스킬 제한

- 동일 적 재침투 시 저항 +25% (최대 50%)
- 보스 "셧다운" 1턴으로 제한
- "데이터 탈취" 보스 스킬 위력 70%
- 전투당 "자폭 명령" 3회 제한

### RAM 밸런스

- 적극적 플레이: RAM 부족 느낌
- 오버클럭 사용 시 HP 리스크
- 장악 스킬(4 GB)은 상당한 투자

## 구현 우선순위

1. 🔲 침투 게이지 시스템 (적별 개별 관리)
2. 🔲 RAM 자원 시스템
3. 🔲 침투 단계별 자동 디버프
4. 🔲 장악 스킬 4종 구현
5. 🔲 프로그램 스킬 → 1회성 전환
6. 🔲 기본 스킬 재설계
7. 🔲 특성 재정비
8. 🔲 궁극기/팀워크 구현
9. 🔲 UI: 침투 게이지 표시
10. 🔲 UI: 장악 스킬 선택 팝업

## 부록: 현재 vs 리메이크 비교

| 항목 | 현재 | 리메이크 |
|------|------|---------|
| 기믹 | 프로그램 상시 가동 | 침투 게이지 축적 |
| 자원 | MP만 | MP + RAM |
| 플레이 | 프로그램 켜두고 대기 | 적 선택 + 침투 축적 + 장악 |
| 목표 | 디버프 유지 | 완전 침투 → 장악 스킬 |
| 리스크 | 없음 | 오버클럭 HP 손실, RAM 관리 |
| 보상 | 지속 디버프 | 강력한 일회성 효과 |
| 상호작용 | 일방적 | 적별 상태 관리 |
