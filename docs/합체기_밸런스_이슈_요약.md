#### 1️⃣ Hybrid 타입 공격력 중복 계산 bug
```
파일: src/combat/combat_manager.py 라인 6523-6526
영향받는 합체기: 원소의 검무 (elemental_blade_dance)

현재 코드:
  if damage_type in ("physical", "hybrid"):
      total_atk += physical_attack
  if damage_type in ("magic", "hybrid"):
      total_atk += magic_attack

문제: Hybrid인 경우 total_atk = physical + magic (평균 아님!)
결과: 피해가 50~100% 높게 계산됨

예) 물리100 + 마법80인 참여자 2명
  현재: (100+80) + (100+80) = 360 → 평균 90
  정상: ((100+80)/2) + ((100+80)/2) = 180 → 평균 45

수정:
  elif damage_type == "hybrid":
      phys = getattr(p, 'physical_attack', 50)
      mag = getattr(p, 'magic_attack', 50)
      total_atk += (phys + mag) / 2
```

#### 3️⃣ 파티 보너스 곱셈 로직 오류
```
파일: src/combat/job_synergy.py 라인 267-271

현재 코드:
  if key in total:
      total[key] = total[key] + value - 1.0 if isinstance(value, float) and value > 1.0 else total[key] + value

문제: 배수를 더하는 방식 (수학 오류)

예) 3가지 보너스 모두 적용:
  physical_dominance: 1.10
  balanced_formation: 1.05
  diverse_party: 1.03

현재: 1.10 + 1.05 - 1.0 + 1.03 - 1.0 = 1.18 (18%)
정상: 1.10 × 1.05 × 1.03 = 1.189 (18.9%)
차이: 0.9% (작지만 틀렸음!)

수정:
  # 곱셈 효과는 곱하기
  if key.endswith('_mult'):
      if key not in result:
          result[key] = 1.0
      result[key] *= value  # 더하기 아니라 곱하기!
  else:
      # 가산값은 더하기
      result[key] = result.get(key, 0) + value
```

### 🟡 중간 (개선 권장)

#### 4️⃣ 방어력 감소 공식 취약
```
파일: src/combat/combat_manager.py 라인 6537

현재:
  actual_damage = max(1, base_damage - defense // 2)

문제: 방어력이 높으면 선형 감소, 극단적 감소 가능

예) 절대영도 최대 피해 1000
  적 방어 150 → 1000 - 75 = 925 (7% 감소)
  적 방어 1000 → 1000 - 500 = 500 (50% 감소)
  적 방어 2000 → max(1, 1000 - 1000) = 1 (0.1% 감소!!)

결과: 게이지 350 쓰고 1 피해 가능

개선:
  defense_ratio = min(0.8, defense / (defense + 100))
  actual_damage = max(1, int(base_damage * (1 - defense_ratio)))

또는:
  actual_damage = max(1, int(base_damage * 0.8 / (1 + defense / 100)))
```

#### 7️⃣ 상태이상 부여 Try-Catch 조용히 실패
```

현재:
  try:
      t.status_manager.apply_status(status, duration=duration)
  except Exception:
      pass  # ← 조용히 실패

문제: 상태이상이 안 걸려도 로그가 없음
      디버깅 어려움

수정:
  try:
      t.status_manager.apply_status(status, duration=duration)
      result["effects"].append({
          "type": "status",
          "target": t.name,
          "status": status,
          "duration": duration
      })
  except Exception as e:
      logger.warning(f"[합체기] 상태이상 부여 실패: {t.name}, {status}, {e}")
```

### 수정 2: 파티 보너스 (10분)
```python
# job_synergy.py 라인 267-271 전체 교체
def get_total_bonus_effects(self) -> Dict[str, float]:
    total = {}
    mult_keys = {}
    for bonus in self._active_bonuses:
        for key, value in bonus.effects.items():
            if key.endswith('_mult') and isinstance(value, float):
                if key not in mult_keys:
                    mult_keys[key] = 1.0
                mult_keys[key] *= value
            else:
                total[key] = total.get(key, 0) + value
    total.update(mult_keys)
    return total
```
