## 2. 세계관

### 2.1 황금시대 (2157년)

인류는 마침내 평화를 이루었다.

- 전쟁은 역사책 속 이야기
- 질병과 기아가 해결됨
- 우주 개척 시대 개막
- 별들 사이를 여행하는 문명

인류는 **차원 항해 기술**을 개발하여 무한한 가능성의 세계로 나아가려 했다.

---

### 2.2 대균열 - 별들이 떨어지는 밤

#### 차원 항해 실험 실패

**그 날 밤**, 인류 최초의 차원 도약 실험이 시작되었다.

하지만...

- 하늘이 갈라졌다
- 대지가 진동했다
- 세계는 산산조각 났다

#### 2158년 1월 15일 - 대균열(The Great Fracture) 발생

- 원인 불명의 시공간 붕괴 현상이 지구에서 시작
- 차원의 경계가 무너지며, 과거와 미래가 뒤섞임
- 수십억 명이 순식간에 사라지거나, 다른 시간대에 갇힘
- **인류 문명은 단 72시간 만에 90% 붕괴**

#### 시공간 붕괴의 증상

- 과거와 미래가 뒤섞임
- 현실의 경계가 흐려짐
- 공간의 법칙이 무너짐
- 차원의 벽이 산산조각

---

### 2.3 조각난 세계

시공간 혼돈으로 인해 세계는 완전히 뒤바뀌었다:

- 과거의 전사가 미래의 땅을 걷는다
- 미래의 과학자가 고대의 유적을 헤맨다
- 죽은 자가 살아 걸어다닌다
- 태어나지 않은 자가 이미 늙어간다
- 미래의 과학자가 돌도끼로 실험을 한다
- 그리스의 철학자가 AI와 함께 진리를 탐구한다
- 해적이 우주선의 성간 항해 길을 개척한다
- 기사가 레이저 검을 다루며 기사도를 지킨다

**모든 것이 무너졌다.**

> 이것이 게임 내 35개의 다양한 시대 출신 직업들이 공존하는 세계관적 근거다.

## 3. 핵심 등장인물

### 3.1 주인공 - 차원 항해사

**"어둠 속에서도 걸어가는 자"**

절망 속에서도 걸어가는 자. 시공간을 넘나들 수 있는 유일한 존재.

#### 사명
- 열 만 번의 밤을 끝낼 자
- 갇힌 영혼을 해방시킬 자
- 어둠을 뚫고 새벽을 맞이할 자

#### 역할
각기 다른 시대에서 온 영웅들과 함께 이 혼돈의 세계에서 질서를 찾아야 한다.
시공 균열을 봉인하고, 세피로스를 해방시키고, 카인을 물리치는 것이 최종 목표.

---

### 3.2 세피로스 - 비극의 영혼

> "날 막아줘... 나를 멈춰줘..."

#### 프로필

| 항목 | 내용 |
|------|------|
| **코드명** | Project-Stellar-001 |
| **본질** | 인류 최후의 희망으로 설계된 존재이자 비극의 희생자 |
| **유전자** | 1,000명의 영웅적 희생자 DNA 융합 |
| **능력** | 시공간 조작, 차원 이동, 무한 재생 |
| **정신 구조** | 10만 개의 타임라인을 동시에 관측 가능 |
| **목적** | 대균열 이전으로 돌아가 역사를 바로잡는 것 |

#### 탄생과 임무 (2167년 8월 12일)

세피로스는 인류수복 프로젝트 "별빛의 여명"의 최종 결과물이다.
그는 영웅이 아닌 **희생자**이며, 구원자가 될 수 없었던 **저주받은 존재**다.

#### 비극의 연쇄 - 10만 번의 반복

세피로스는 시공의 문을 열고 과거로 떠났다. 매번 대균열의 원인을 찾아 파괴했지만, 인류는 다른 원인으로 멸망했다:

| 타임라인 | 멸망 원인 |
|----------|----------|
| 1번째 | 대균열은 막았지만, 핵전쟁으로 멸망 |
| 2번째 | 핵전쟁 원인 제거 후 AI 반란으로 멸망 |
| 12번째 | 팬데믹으로 멸망 |
| 37번째 | 태양 폭발로 멸망 |
| 89번째 | 외계 침공으로 멸망 |
| 203번째 | 인류 자멸 (자원 고갈) |
| 1,247번째 | 차원 붕괴 재발 |
| 8,956번째 | 우주 자체의 소멸 |
| **10,000번째** | **깨달음: "인류의 멸망은 피할 수 없다"** |

#### 조작된 운명

**카인은 세피로스를 실패하도록 설계했다.**

- 뇌에 숨겨진 리미터
- 성공에 가까워지면 무의식적으로 실패
- 진실을 깨닫지 못하도록 조작
- 영원히 고통받도록 설계

세피로스는 **카인의 도구**였다.

#### 정신 붕괴

10만 개의 타임라인을 관측한 세피로스는 미쳐갔다:

- 과거, 현재, 미래의 구분 상실
- 자아 정체성 붕괴 (1,000명의 DNA 주인들의 기억이 뒤섞임)
- 목적 상실 (무엇을 구해야 하는가?)
- 존재 이유 상실 (왜 존재하는가?)

#### 마지막 결정

세피로스는 시공의 틈새 가장 깊은 곳(20층)에 자신을 봉인했다.

**이유:**
1. 자신이 움직일수록 타임라인이 더 붕괴된다는 것을 깨달음
2. 인류를 구할 수 없다면, 최소한 더 망치지는 말아야 함
3. 하지만 그는 죽을 수 없음 (무한 재생 능력)

**세피로스의 소망:**
10만 번의 반복 끝에, 세피로스는 단 하나를 바란다.
강력한 존재가 나타나, 자신을 완전히 파괴해주기를.

> "날 막아줘... 날 멈춰줘..."

**그는 자유를 원한다.**

### 3.3 닥터 아벨 카인 - 진정한 악

> "나는 신이야. 과거도, 현재도, 미래도 내 손안에 있지."

#### 프로필

| 항목 | 내용 |
|------|------|
| **이름** | 아벨 카인 (Dr. Abel Cain) |
| **직함** | 별빛의 여명 프로젝트 총책임자, 시공간물리학 박사 |
| **외견** | 40대 (실제 나이 불명) |
| **성격** | 차갑고 계산적, 완벽주의자, 감정이 없는 듯한 눈빛 |
| **본질** | 영원을 꿈꾼 자, 신이 되려 한 자 |

#### 이름의 상징

**아벨(Abel)** + **카인(Cain)** = 성경의 형제 살해 이야기

- 아벨: 신에게 사랑받은 동생 (희생자)
- 카인: 질투로 동생을 죽인 형 (가해자)
- 그의 이름은 **희생자와 가해자를 동시에 상징**한다
- 세피로스를 만들고(아벨), 그를 지옥으로 밀어넣은(카인) 자

#### 카인의 진짜 목적

**불멸(Immortality)**

카인은 어린 시절부터 죽음을 두려워했다.
그는 천재였지만, 천재도 죽는다는 사실이 견딜 수 없었다.

> "왜 나같은 존재가 사라져야 하는가?"
> "인류의 99.9%는 무가치하다. 나 하나가 영원히 사는 것이 더 가치있다."

인류수복위원회에는 이렇게 말했다:
> "시공간을 넘어 역사를 수정할 병기를 만들겠습니다."

하지만 인류를 구하려 한 것이 아니다. **그는 신이 되고 싶었다.**

#### 카인의 계획 (5단계)

| Phase | 계획 | 상태 |
|-------|------|------|
| **1** | 세피로스를 시공간 조작 능력을 가진 존재로 만든다 | 완료 |
| **2** | 세피로스에게 무한히 타임라인을 반복하게 한다 | 완료 |
| **3** | 그 과정에서 축적된 시공간 데이터를 빼낸다 | 완료 |
| **4** | 그 데이터로 자신의 의식을 시공간에 고정 (불멸 획득) | 완료 |
| **5** | 모든 타임라인을 파괴하고, 자신만의 완벽한 세계를 창조 | **최종 목표** |

**카인은 이제 시간의 왕이다.**

- 과거에도 존재하고
- 미래에도 존재하고
- 모든 타임라인에 동시에 존재한다

> "나만이 존재하는 영원한 세계. 더 이상 쓸모없는 인류는 필요 없다."

## 10. 전투 시스템의 세계관적 의미

### ATB + BRV 하이브리드

```
┌─────────────────────────────────────────────────────────────────┐
│  [ATB 게이지]                                                    │
│  0 ─────────────── 1000 ─────────────── 2000                    │
│                     ↑ 행동 가능                                  │
│                                                                  │
│  [전투 흐름]                                                     │
│  ATB 충전 → BRV 공격(용기 축적) → HP 공격(실제 피해) → BREAK!  │
└─────────────────────────────────────────────────────────────────┘
```

| 시스템 | 수치 | 세계관적 의미 |
|--------|------|--------------|
| **ATB** | 0~2000 (1000에서 행동) | 시공간 속 행동 타이밍 |
| **BRV** | 기본 1000 | 용기. 축적한 용기를 실제 피해로 전환 |
| **BREAK** | BRV 0 도달 | 적의 용기를 완전히 꺾음. +50% 보너스 + 스턴 |
| **상처** | HP 피해의 25% | 시공간 왜곡으로 인한 영구적 손상 |

### 스킬 타입

| 타입 | 설명 |
|------|------|
| BRV 공격 | BRV만 축적 (HP 데미지 없음) |
| HP 공격 | 축적된 BRV로 HP 데미지 |

## 14. 핵심 철학과 메시지

### "시간은 매정하지만 공평하다"

이 게임의 중심 테마. 세 인물의 선택을 통해 드러난다:

| 인물 | 선택 | 결과 |
|------|------|------|
| **카인** | 영원을 추구 | 고독과 공허 → 패배 |
| **세피로스** | 포기하지 않음 | 해방과 안식 |
| **주인공** | 불꽃처럼 타오름 | 전설이 됨 |

### 핵심 메시지들

1. **시간의 공평함**
   - 영원을 꿈꾸는 자에게도, 불꽃처럼 타오르는 자에게도 시간은 똑같이 흐른다
   - 하지만 그 안에서 무엇을 만드는지는 우리의 선택이다

2. **희망의 불멸**
   - 가장 긴 밤 끝에는 반드시 새벽이 온다
   - 가장 깊은 어둠 속에서도 빛은 길을 찾아낸다
   - 별이 떨어진 자리에 꽃을 피워낼 것이다

3. **유한함의 아름다움**
   - 카인은 영원을 손에 넣었지만 공허했다
   - 불꽃처럼 타오르는 것이 영원히 사는 것보다 아름답다
   - 유한한 존재이기에 빛날 수 있다

4. **세피로스의 교훈**
   - 10만 번의 반복 속에서 단 한 번의 희망
   - 아무리 많은 실패를 겪어도, 포기하지 않는 것에 의미가 있다
