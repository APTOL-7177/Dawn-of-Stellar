## 📝 Suno AI 사용 팁

1. **Custom Mode** 선택
2. 스타일 프롬프트를 "Style of Music" 필드에 입력
3. 가사를 "Lyrics" 필드에 복사 붙여넣기
4. **Extended Mode** 활성화 (7-8분 곡)
5. 여러 번 생성하여 최적의 버전 선택
