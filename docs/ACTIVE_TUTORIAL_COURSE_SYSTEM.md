# 액티브 튜토리얼 코스 시스템 기획

> Dawn of Stellar의 모든 시스템을 단계별로 학습할 수 있는 종합 튜토리얼 시스템

---

## 📋 개요

뉴비들이 복잡한 게임 시스템(ATB + BRV 하이브리드, 34개 직업 기믹, 요리 등)을 **실습 기반**으로 자연스럽게 배울 수 있도록 설계된 코스 시스템입니다.

### 핵심 철학
- **Learn by Doing**: 설명보다 직접 행동
- **Progressive Disclosure**: 단계적 공개로 인지 과부하 방지
- **Contextual Learning**: 게임 플레이 중 필요한 시점에 학습
- **Adaptive Difficulty**: 플레이어 숙련도에 맞게 조정

---

## 📖 스토리 연계 시스템

### 세계관 배경 (인트로 스토리 기반)

> **서기 2157년, 지구**
> 
> 인류는 마침내 차원 항해 기술을 완성했다.
> 하지만 첫 번째 차원 도약 실험에서 아무도 예상하지 못한 일이 벌어졌다.
> 
> **시공간 교란 발생!**
> 
> 하늘이 갈라지고 대지가 진동했다. 차원의 경계가 산산조각 나면서
> 과거, 현재, 미래의 모든 시대가 뒤섞이기 시작했다.
> 
> - 미래의 과학자가 돌도끼로 실험을 한다
> - 그리스의 철학자가 AI와 함께 진리를 탐구한다
> - 해적이 우주선의 성간 항해 길을 개척한다
> - 기사가 레이저 검을 다루며 기사도를 지킨다
> 
> 당신은 **차원 항해사**... 시공간을 넘나들 수 있는 유일한 존재.
> 각기 다른 시대에서 온 영웅들과 함께 이 혼돈의 세계에서 질서를 찾아야 한다.

### 🎁 튜토리얼 완료 보상

> **스토리적 연결**
> 
> 시공 교란을 일으킨 차원 항해 실험에서 살아남은 당신...
> 첫 번째 시공 균열을 닫는 순간, 뒤섞인 시간의 에너지가 당신 안에서 각성한다.

### 최종 보상

| 항목 | 보상 |
|------|------|
| **직업 해금** | 시간술사/차원술사/해커 중 1개 선택 |
| **별의 파편** | 100개 (메타 진행 해금에 사용) |

> 별의 파편은 새로운 직업, 특성, 영구 업그레이드 등 메타 진행을 해금하는 데 사용됩니다.

```yaml
tutorial_completion_reward:
  job_unlock:
    id: "time_mage"  # 기본 추천
    name: "시간술사"
    cost: 0  # 무료 해금
    story_reason: "시공 균열 봉인으로 시간의 힘 각성"
    
  stellar_fragments: 100  # 별의 파편 (메타 진행 해금용)
```

### 🤔 왜 시간술사인가?

| 이유 | 설명 |
|------|------|
| **세계관 일치** | 시공 교란이 원인 → 시간 조작 능력 각성이 자연스러움 |
| **스토리 연결** | 차원 항해사가 시간의 힘을 얻는 플롯 |
| **게임플레이 확장** | 기본 직업과 완전히 다른 "타임라인" 기믹 체험 |
| **초보자 친화** | 현재(0) 유지 = 쉬운 플레이, 숙련되면 시간 조작 |
| **희귀 직업 체험** | 해금 필요한 24개 직업 중 하나를 무료로 경험 |
