## 🌍 세계관 및 스토리

### 배경

> **서기 2157년, 지구**
> 
> 인류는 마침내 차원 항해 기술을 완성했다.
> 하지만 첫 번째 차원 도약 실험에서 아무도 예상하지 못한 일이 벌어졌다.
> 
> **시공간 교란 발생!**
> 
> 하늘이 갈라지고 대지가 진동했다. 차원의 경계가 산산조각 나면서
> 과거, 현재, 미래의 모든 시대가 뒤섞이기 시작했다.

### 뒤섞인 세계

- 미래의 과학자가 돌도끼로 실험을 한다
- 그리스의 철학자가 AI와 함께 진리를 탐구한다
- 해적이 우주선의 성간 항해 길을 개척한다
- 기사가 레이저 검을 다루며 기사도를 지킨다

### 플레이어의 역할

당신은 **차원 항해사**... 시공간을 넘나들 수 있는 유일한 존재.
각기 다른 시대에서 온 영웅들과 함께 이 혼돈의 세계에서 질서를 찾아야 한다.

---

## 🎯 게임의 목적

1. **시공 균열 봉인**: 세계 곳곳에 발생한 차원 균열을 닫고 세계를 안정화
2. **파티 구성**: 다양한 시대에서 온 33개 직업의 영웅들을 모집하여 최강의 파티 구성
3. **던전 탐험**: 절차적으로 생성되는 무한한 던전을 탐험하며 성장
4. **메타 진행**: 별의 파편을 수집하여 영구적인 업그레이드와 새로운 콘텐츠 해금

## ⚔️ 핵심 전투 시스템

### ATB + BRV 하이브리드 시스템

Dawn of Stellar의 전투는 Final Fantasy의 **ATB(Active Time Battle)**와 Dissidia의 **BRV(Brave)** 시스템을 결합한 독창적인 방식입니다.

```
┌─────────────────────────────────────────────────────────────────┐
│  [ATB 게이지]                                                    │
│  0 ─────────────── 1000 ─────────────── 2000                    │
│                     ↑ 행동 가능                                  │
│                                                                  │
│  [전투 흐름]                                                     │
│  ATB 충전 → BRV 공격(데미지 축적) → HP 공격(실제 피해) → BREAK! │
└─────────────────────────────────────────────────────────────────┘
```

### 전투 흐름

| 단계 | 설명 |
|------|------|
| **1. ATB 충전** | 실시간으로 게이지가 충전되며, 1000 이상이 되면 행동 가능 |
| **2. BRV 공격** | 적의 BRV를 빼앗아 자신의 BRV로 축적 (HP 데미지 없음) |
| **3. HP 공격** | 축적된 BRV를 소모하여 실제 HP 데미지 |
| **4. BREAK** | 적의 BRV를 0으로 만들면 **BREAK** 발동 → +50% 보너스 데미지 + 스턴 |

### 스킬 타입

| 타입 | 설명 |
|------|------|
| **BRV 공격** | BRV만 축적 (HP 데미지 없음) |
| **HP 공격** | 축적된 BRV로 HP 데미지 |
| **BRV+HP 공격** | 둘 다 동시에 (강력한 기술) |
| **서포트** | 아군 버프, 회복 |
| **디버프** | 적 약화 |
| **궁극기** | 강력한 필살기 |

## 🎮 게임 흐름

### 기본 진행

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│ 파티 선택   │ → │  던전 입장   │ → │  전투/탐험  │ → │   보스 전투  │
│ (4명 고정) │    │  (절차 생성) │    │ (ATB+BRV)  │    │             │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
                                                                ↓
┌─────────────┐    ┌─────────────┐                       ┌─────────────┐
│  메타 진행   │ ← │  별조각 획득 │ ←───────────────────│   승리/패배  │
│ (영구 강화) │    │             │                       │             │
└─────────────┘    └─────────────┘                       └─────────────┘
```

### 탐험 사이클

1. **파티 선택**: 게임 시작 전 33개 직업 중 4명 선택 (게임오버까지 변경 불가)
2. **던전**: 절차적으로 생성된 층을 탐험
3. **전투**: 랜덤 적과 ATB+BRV 전투
4. **보스**: 각 구역의 보스 처치
5. **결과**: 승리/게임오버 → 별조각으로 메타 진행

### 💎 메타 진행 (별의 파편)

게임 플레이로 **별의 파편**을 획득하여:

- **새 직업 해금**: 초기 9개 → 33개 전체
- **패시브 스킬 구매**: 영구 강화
- **마을 시설 업그레이드**: 대장간, 주방, 상점 등
- **특성 해금**: 캐릭터 커스터마이징

### 🎒 장비 & 인벤토리

- **무기/방어구/악세서리** 장착
- **내구도 시스템**: 장비 수리 필요
- **제작**: 대장간에서 새 장비 제작

## 🏰 던전 시스템

### 절차적 생성

- **BSP(Binary Space Partitioning)** 알고리즘으로 매번 다른 맵
- 랜덤 적, 아이템, 보물 배치
- 층마다 난이도 상승

### 보스

- 구역별 보스 존재
- HP% 별 패턴 변화 (페이즈 시스템)
- 보스 처치 시 대량의 경험치와 별조각 획득
