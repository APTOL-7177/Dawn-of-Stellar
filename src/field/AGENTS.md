# 필드 스킬 시스템

## 목적
탐색 중에 사용할 수 있는 특수 스킬들을 관리합니다. 요리, 채집, 기타 필드 활동을 포함합니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| cooking.py | 필드 요리 스킬 |
| gathering.py | 필드 채집 스킬 |
| field_skills.py | 기타 필드 스킬 |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- 필드 스킬은 전투 중에는 사용할 수 없습니다 (탐색 전용).
- 스킬은 직업별로 습득됩니다.
- 스킬 사용은 특정 조건(재료 보유, 쿨타임)을 확인합니다.

### 테스트 요구사항
- 필드 스킬 사용 조건이 정확한지 검증합니다.
- 스킬 효과가 올바르게 적용되는지 확인합니다.
- 쿨타임 추적이 정확한지 검증합니다.

### 일반적인 패턴
- 필드 스킬은 메뉴에서 선택 가능합니다.
- 스킬 사용은 상황에 따라 성공/실패할 수 있습니다.

## 의존성

- `src/gathering/` - 채집 시스템
