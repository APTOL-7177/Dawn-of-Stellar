# 채집 시스템

## 목적
게임 월드에서 재료를 채집하는 시스템. 플레이어는 몬스터 드롭, 환경 객체(풀, 돌, 광석)에서 재료를 수집합니다. 재료 타입, 채집 조건, 드롭 확률을 정의합니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| ingredient.py | 재료 정의 (ID, 이름, 타입, 아이콘) |
| harvestable.py | 채집 가능한 환경 객체 (풀, 돌, 광석 등) |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- 재료는 게임 월드의 환경 타일에 배치됩니다.
- 몬스터는 처치 시 재료를 드롭합니다 (확률 기반).
- 플레이어는 채집 가능한 타일과 상호작용하여 재료를 얻습니다.
- 채집 성공률은 플레이어 기술 또는 100% 확률일 수 있습니다.

### 테스트 요구사항
- 재료 드롭 확률이 올바르게 적용되는지 검증합니다.
- 채집 가능한 객체가 올바른 재료를 반환하는지 확인합니다.
- 채집 후 환경 객체 제거를 검증합니다.
- 재료 중복 없는지 확인합니다.

### 일반적인 패턴
- 재료는 불변 데이터입니다 (템플릿).
- 각 몬스터 타입은 드롭 테이블을 가집니다 (재료 확률).
- 환경 채집은 상호작용으로 진행되고 즉시 완료됩니다.

## 의존성
### 내부
- `src/world/` - 타일 배치, 환경 객체
- `src/cooking/` - 재료 사용 (요리)
- `src/equipment/` - 재료 추가 (인벤토리)

### 외부
- `pydantic` - 재료 모델 검증
