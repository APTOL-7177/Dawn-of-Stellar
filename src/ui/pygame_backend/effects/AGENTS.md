# 시각 효과 시스템

## 목적
게임 화면의 모든 시각 효과를 관리합니다. 파티클 시스템, 화면 왜곡 효과, CRT 필터, 글로우, 번개, 텍스트 애니메이션, 장면 전환 등을 구현합니다. 전투 스킬 이펙트, 상태 이상 표시, 환경 특수 효과를 포함합니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| base.py | 효과 기본 클래스 (모든 효과의 부모) |
| particles.py | 파티클 시스템 (폭발, 혈흔, 치유 파티클) |
| skill_effects.py | 스킬 이펙트 (공격 이펙트, 마법 이펙트) |
| screen_effects.py | 화면 효과 (화면 흔들림, 플래시) |
| transition.py | 장면 전환 (페이드 인/아웃, 슬라이드) |
| crt.py | CRT 모니터 필터 |
| glitch.py | 글리치 효과 (왜곡, 스캔라인) |
| glow.py | 글로우/블룸 효과 |
| lighting.py | 동적 조명 효과 |
| text_effects.py | 텍스트 애니메이션 (떨림, 페이드) |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- 모든 효과는 `base.py`의 기본 클래스를 상속합니다.
- 효과는 프레임 단위로 업데이트되며 `update()` 메서드를 구현합니다.
- 효과는 `render()` 메서드로 Pygame 표면에 그려집니다.
- 효과 생명주기: 생성 → 업데이트(여러 프레임) → 완료.

### 테스트 요구사항
- 효과 타이밍은 프레임 카운트로 검증합니다.
- 시각적 렌더링은 스크린샷 비교로 검증합니다.
- 파티클 개수가 많을 때 성능 저하를 측정합니다.

### 일반적인 패턴
- 효과는 `duration` 프레임 동안 실행됩니다.
- 알파 채널은 시간에 따라 변합니다 (페이드 인/아웃).
- 파티클은 개별 위치, 속도, 생명주기를 가집니다.

## 의존성
### 내부
- `src/ui/pygame_backend/` - Pygame 렌더링

### 외부
- `pygame` - 게임 렌더링
- `numpy` - 파티클 벡터 연산
