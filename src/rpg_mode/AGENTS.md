# RPG 모드

## 목적
자유로운 탐색 기반의 RPG 게임플레이. 동적으로 생성되는 맵, 무한 던전, 지역 기반 허브 시스템을 포함합니다. 플레이어는 자신의 속도로 세계를 탐색하며 경험을 쌓습니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| rpg_mode_manager.py | RPG 모드 상태 관리 |
| rpg_world_generator.py | 동적 맵 생성 |
| rpg_world_config.py | 세계 설정 (난이도, 보상) |
| rpg_region_hub.py | 지역 허브 관리 |
| rpg_chapter_system.py | RPG 챕터 구조 (선택 사항) |
| party_builder.py | 파티 커스터마이징 |
| lazy_tile_map.py | 지연 로딩 맵 (메모리 최적화) |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- RPG 모드는 절차적 생성 알고리즘을 사용합니다.
- 난이도는 플레이 시간 또는 플레이어 레벨에 따라 조정됩니다.
- 지역 허브는 고정된 위치이며, 던전은 무한 생성 가능합니다.
- 맵 생성은 결정론적입니다 (같은 시드 = 같은 맵).

### 테스트 요구사항
- 맵 생성이 올바르게 작동하는지 검증합니다.
- 난이도 조정이 예상 범위 내인지 확인합니다.
- 지역 허브가 올바르게 로드되는지 검증합니다.
- 메모리 사용량이 합리적인지 측정합니다 (지연 로딩).

### 일반적인 패턴
- 맵 생성은 세드 기반입니다 (재현성).
- 몬스터는 플레이어 레벨에 따라 스케일됩니다.
- 보상도 난이도에 따라 스케일됩니다.

## 의존성
### 내부
- `src/world/` - 기본 던전 생성
- `src/character/` - 캐릭터 정보
- `src/combat/` - 전투 시스템
- `src/equipment/` - 아이템 생성

### 외부
- `pyyaml` - 설정 로드
- `pydantic` - 모델 검증
