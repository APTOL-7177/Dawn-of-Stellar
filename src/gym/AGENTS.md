# RL 학습 환경 (Gym)

## 목적
강화학습 알고리즘 훈련을 위한 OpenAI Gym 호환 게임 환경. 게임 상태 인코딩, 행동 공간, 보상 함수를 정의합니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| combat_env.py | 전투 환경 (Gym API) |
| action_space.py | 행동 공간 정의 |
| state_encoder.py | 게임 상태를 벡터로 인코딩 |
| reward_shaper.py | 보상 함수 설계 |
| episode_manager.py | 에피소드 관리 |
| headless_combat.py | GUI 없는 전투 시뮬레이션 |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- Gym API를 따릅니다 (reset(), step(), render()).
- 상태는 numpy 배열로 반환됩니다.
- 행동은 정수 인덱스입니다.
- 보상은 실수 스칼라입니다.
- 에피소드는 terminal 플래그로 종료됩니다.

### 테스트 요구사항
- 환경이 Gym API를 정확히 구현하는지 검증합니다.
- 상태 인코딩이 일관성 있고 정보를 잃지 않는지 확인합니다.
- 보상 함수가 의도한 행동을 유도하는지 검증합니다.
- 성능 측정 (에피소드 시뮬레이션 속도).

### 일반적인 패턴
- 상태는 고정 크기 벡터입니다 (신경망 입력용).
- 행동은 이산적입니다 (스킬 선택, 이동).
- 보상은 전투 성과에 기반합니다 (피해량, 생존 등).

## 의존성
### 내부
- `src/character/` - 캐릭터 데이터
- `src/combat/` - 전투 시뮬레이션
- `src/world/` - 환경 데이터

### 외부
- `gymnasium` (또는 `gym`) - 강화학습 환경 API
- `numpy` - 벡터 연산
- `torch` (옵션) - 신경망 (RL 훈련용)
