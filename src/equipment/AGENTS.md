# 장비 시스템

## 목적
게임의 장비, 아이템, 인벤토리 관리. 장비 효과 적용, 내구도 시스템, 아이템 정렬, 상태 저장을 포함합니다. 플레이어는 무기, 방어구, 액세서리를 장착하고 속성과 효과를 얻습니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| item_system.py | 아이템 정의 및 속성 (무기, 방어구, 소비 아이템) |
| inventory.py | 인벤토리 관리 (추가, 제거, 정렬) |
| equipment_effects.py | 장비 효과 적용 (속성 버프, 상태 이상 저항) |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- 모든 아이템은 속성(ID, 이름, 타입, 가격, 효과)을 가집니다.
- 장비는 `equipment_effects.py`를 통해 캐릭터에 효과를 적용합니다.
- 인벤토리는 슬롯 기반이거나 무제한 수용량입니다 (게임 설정에 따라).
- 내구도는 아이템 별로 추적됩니다 (선택 사항).

### 테스트 요구사항
- 아이템 추가/제거 시 인벤토리 일관성을 검증합니다.
- 장비 장착 시 효과 적용을 검증합니다.
- 인벤토리 저장/로드가 정확한지 확인합니다.
- 내구도 감소 로직을 검증합니다.

### 일반적인 패턴
- 아이템은 불변 데이터(예: 무기 템플릿)와 인스턴스 상태(내구도)로 분리됩니다.
- 효과는 캐릭터 속성에 추가/제거됩니다 (스택 가능).
- 인벤토리는 아이템 리스트와 선택된 장비 슬롯을 관리합니다.

## 의존성

- `src/character/` - 캐릭터 속성 계산
- `src/combat/` - 전투 효과

### 외부
- `pydantic` - 아이템 모델 검증
