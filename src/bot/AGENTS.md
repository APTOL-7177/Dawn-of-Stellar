# 봇 시스템

## 목적
게임 상태를 데이터 형식으로 내보내는 시스템. 주로 AI 분석, 재생 검토, 디버깅에 사용됩니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| game_state_exporter.py | 게임 상태를 JSON/YAML로 내보내기 |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- 게임 상태는 캐릭터, 아이템, 맵 정보를 포함합니다.
- 내보내기는 읽기 전용 작업입니다 (게임 상태 변경 없음).
- 내보낸 데이터는 외부 분석 도구에서 사용됩니다.

### 테스트 요구사항
- 내보낸 데이터가 완전하고 일관성 있는지 검증합니다.
- JSON 직렬화가 성공하는지 확인합니다.
- 대용량 게임 상태 내보내기 성능을 측정합니다.

### 일반적인 패턴
- 내보내기는 현재 게임 상태의 스냅샷입니다.
- 중요한 정보만 선택적으로 내보낼 수 있습니다.

## 의존성
### 내부
- `src/character/` - 캐릭터 정보
- `src/combat/` - 전투 상태
- `src/world/` - 맵 정보
- `src/equipment/` - 인벤토리

### 외부
- `json` - JSON 직렬화
- `pydantic` - 데이터 검증
