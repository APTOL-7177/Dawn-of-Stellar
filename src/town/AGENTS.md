# 타운 시스템

## 목적
중앙 허브 지역(마을)을 관리합니다. 플레이어는 여기서 던전을 선택, 파티를 구성, 아이템을 구매/판매합니다. 맵 전환, 층 이동을 포함합니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| town_manager.py | 타운 상태 관리 |
| town_map.py | 타운 맵 렌더링 및 상호작용 |
| floor_transition.py | 층 간 이동 처리 |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- 타운은 고정된 맵입니다 (절차적 생성 없음).
- 플레이어는 타운에서 안전하게 준비할 수 있습니다 (몬스터 없음).
- 층 전환은 지정된 타일에서만 가능합니다.
- 타운 상태는 저장/로드에 포함됩니다.

### 테스트 요구사항
- 타운 맵이 올바르게 로드되는지 검증합니다.
- 상호작용 가능한 NPC/오브젝트가 올바르게 작동하는지 확인합니다.
- 층 전환이 올바른 맵으로 이동하는지 검증합니다.
- 타운 상태 저장/로드가 정확한지 확인합니다.

### 일반적인 패턴
- 타운은 정적 맵이므로 성능 최적화가 필요하지 않습니다.
- NPC는 고정 위치에 있습니다.
- 상호작용은 거리 기반 또는 타일 기반입니다.

## 의존성
### 내부
- `src/world/` - 기본 맵 렌더링
- `src/character/` - 플레이어 정보
- `src/ui/` - UI 렌더링

### 외부
- `pyyaml` - 타운 설정 로드
