# 스토리 모드

## 목적
스토리 기반 캠페인 게임플레이. 선형 스토리라인, 챕터 구조, 캐릭터 개발을 포함합니다. 스토리 모드는 튜토리얼과 통합되어 신규 플레이어를 위한 가이드를 제공합니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| story_mode_manager.py | 스토리 모드 상태 관리 |
| chapter_runner.py | 챕터 실행 엔진 |
| chapter_select_ui.py | 챕터 선택 메뉴 |
| story_combat_controller.py | 스토리 전투 제어 |
| story_exploration_controller.py | 스토리 탐색 제어 |
| inline_tutorial_overlay.py | 스토리 중 튜토리얼 오버레이 |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- 스토리 모드는 여러 챕터로 구성됩니다.
- 각 챕터는 고정된 난이도와 진행 경로를 가집니다.
- 튜토리얼은 스토리 진행 중에 나타나 게임 메카닉을 설명합니다.
- 스토리 전투와 탐색은 일반 모드와 유사하지만, 진행 추적이 다릅니다.

### 테스트 요구사항
- 모든 챕터가 완료 가능함을 검증합니다.
- 스토리 진행이 순서대로 이루어지는지 확인합니다.
- 튜토리얼 오버레이가 올바르게 표시되는지 검증합니다.
- 챕터 완료 후 다음 챕터로의 전환이 매끄러운지 확인합니다.

### 일반적인 패턴
- 챕터는 고정된 몬스터, 미션을 가집니다.
- 진행은 조건(보스 처치, 아이템 수집)으로 결정됩니다.
- 실패 시 재시작 옵션이 제공됩니다.

## 의존성
### 내부
- `src/story/` - 스토리 시스템
- `src/character/` - 캐릭터 정보
- `src/combat/` - 전투 시스템
- `src/world/` - 던전 생성
- `src/tutorial/` - 튜토리얼 통합
- `src/ui/` - UI 렌더링

### 외부
- `pyyaml` - 챕터 정의 로드
- `pydantic` - 스토리 모델 검증
