# 요리/제작 시스템

## 목적
요리와 폭탄 제작 시스템. 플레이어는 재료를 수집하여 음식(회복, 버프), 약물(상태 이상 치료), 폭탄(전투 소비 아이템)을 제작합니다. 레시피 기반 제작, 재료 관리, 성공/실패 확률을 포함합니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| recipe.py | 레시피 정의 (재료, 결과, 효과) |
| potion_brewing.py | 포션 제조 시스템 (음식, 약물) |
| bomb_crafting.py | 폭탄 제작 시스템 (폭발성 아이템) |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- 모든 레시피는 `recipe.py`에 정의됩니다 (YAML 또는 코드).
- 제작은 재료 확인 → 효과 계산 → 아이템 생성 순서로 진행됩니다.
- 제작 성공률은 플레이어 기술 또는 확률로 결정될 수 있습니다.
- 제작 결과는 인벤토리에 추가됩니다.

### 테스트 요구사항
- 각 레시피의 재료 검증이 정확한지 확인합니다.
- 제작 성공/실패 확률을 검증합니다.
- 결과 아이템이 올바른 효과를 가지는지 확인합니다.
- 재료 부족 시 오류 처리를 검증합니다.

### 일반적인 패턴
- 레시피는 `{재료 목록} + {효과} → {결과 아이템}` 형식입니다.
- 제작 과정은 전투 중에 일어날 수 없습니다 (탐색 중만).
- 제작 시간은 없습니다 (즉시 완료).

## 의존성
### 내부
- `src/equipment/` - 결과 아이템 추가
- `src/gathering/` - 재료 타입
- `src/character/` - 플레이어 기술 (옵션)

### 외부
- `pyyaml` - 레시피 YAML 로드
- `pydantic` - 레시피 모델 검증
