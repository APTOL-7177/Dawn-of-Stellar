# 저장/로드 시스템

## 목적
게임 진행 상황을 저장하고 로드합니다. 플레이어 상태, 인벤토리, 퀘스트 진행, 월드 상태를 JSON/바이너리로 저장합니다. 메타 진행도(영구 언락, 업적)도 관리합니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| save_system.py | 게임 진행 저장/로드 (세이브 파일 I/O) |
| meta_progress.py | 메타 진행도 (영구 언락, 통계, 업적) |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- 저장 파일은 JSON 형식입니다 (읽기 가능하고 검증 가능).
- 메타 진행도는 게임 재시작 후에도 유지됩니다 (전역 상태).
- 저장은 동기적으로 수행되며, 실패 시 오류를 반환합니다.
- 버전 호환성을 고려하여 마이그레이션 경로를 제공합니다.

### 테스트 요구사항
- 저장 후 로드하여 상태가 일치하는지 검증합니다 (라운드 트립).
- 부패된 세이브 파일 처리를 검증합니다.
- 메타 진행도가 모든 게임 재시작 후 유지되는지 확인합니다.
- 버전 마이그레이션이 정확한지 검증합니다.

### 일반적인 패턴
- 저장 파일은 `game_saves/save_<slot>.json` 형식입니다.
- 각 세이브는 타임스탬프, 플레이 시간, 진행률을 포함합니다.
- 로드 실패 시 자동으로 백업 세이브를 시도합니다.

## 의존성
### 내부
- `src/character/` - 캐릭터 상태
- `src/combat/` - 전투 상태 (옵션)
- `src/equipment/` - 인벤토리
- `src/quest/` - 퀘스트 진행
- `src/achievement/` - 업적 추적

### 외부
- `json` - JSON 직렬화
- `pathlib` - 파일 경로 관리
- `pydantic` - 저장 데이터 검증
