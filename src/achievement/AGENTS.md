# 업적 시스템

## 목적
게임의 업적 및 마일스톤을 관리합니다. 플레이어는 특정 조건을 달성하여 업적을 언락하고, 보상을 받습니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| achievement_manager.py | 업적 상태 관리 |
| achievement_system.py | 업적 정의 및 검증 |
| milestone_system.py | 마일스톤 관리 (선택 사항) |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- 업적은 조건(값 누적, 이벤트 발생)으로 달성됩니다.
- 각 업적은 ID, 설명, 보상을 가집니다.
- 업적 달성은 플레이어 행동을 감지하여 자동 업데이트됩니다.
- 업적은 메타 진행도에 저장됩니다 (게임 재시작 후 유지).

### 테스트 요구사항
- 업적 조건이 정확하게 평가되는지 검증합니다.
- 업적 달성이 정확하게 감지되는지 확인합니다.
- 보상이 올바르게 지급되는지 검증합니다.
- 중복 달성이 방지되는지 확인합니다.

### 일반적인 패턴
- 업적은 YAML 또는 코드로 정의됩니다.
- 진행도는 0 ~ 100% 또는 불린 값입니다.
- 업적 달성 시 통지 UI가 표시됩니다.

## 의존성
### 내부
- `src/persistence/` - 메타 진행도 저장
- `src/character/` - 플레이어 행동 감지

### 외부
- `pyyaml` - 업적 정의 로드
- `pydantic` - 업적 모델 검증
