# 상처 게이지 시스템

## 목적
게임의 특수 게이지 시스템을 관리합니다. 상처 게이지, 팀워크 게이지 등의 특수 상태를 추적합니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| wound_system.py | 상처 게이지 및 관련 메카닉 |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- 상처 게이지는 캐릭터 상태의 일부입니다.
- 게이지는 0 ~ 100 범위입니다.
- 특정 행동(스킬, 방어)이 게이지에 영향을 미칩니다.
- 게이지 임계값은 특수 효과를 트리거할 수 있습니다.

### 테스트 요구사항
- 게이지 증감이 정확한지 검증합니다.
- 임계값 트리거가 올바르게 작동하는지 확인합니다.
- 게이지 저장/로드가 정확한지 검증합니다.

### 일반적인 패턴
- 게이지는 매 턴 특정 량만큼 감소하거나 증가합니다.
- 최댓값 도달 시 특수 상태가 활성화됩니다.
- 게이지는 시간 경과로도 자동 변합니다.
