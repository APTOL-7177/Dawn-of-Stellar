# 강화학습 에이전트

## 목적
강화학습 모델의 훈련, 평가, 배포. PPO, 행동 복제, 모델 내보내기를 포함합니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| ppo_trainer.py | PPO 알고리즘 훈련 |
| behavioral_cloning.py | 행동 복제 (전문가 데이터로부터 학습) |
| network.py | 신경망 아키텍처 (정책, 가치 함수) |
| rl_bot.py | 훈련된 모델을 사용하는 게임 봇 |
| evaluation.py | 모델 평가 및 성능 측정 |
| model_export.py | 모델 저장 및 로드 |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- PPO는 정책 그래디언트 알고리즘입니다.
- 행동 복제는 전문가 데이터(플레이 기록)로 초기화합니다.
- 모델은 Gym 환경과 상호작용하여 훈련됩니다.
- 평가는 확률론적이므로 여러 번 실행해야 합니다.

### 테스트 요구사항
- 훈련이 수렴하는지 확인합니다 (보상 증가).
- 평가 결과가 일관성 있는지 검증합니다.
- 모델 저장/로드가 정확한지 확인합니다.
- 배포 성능 (인퍼런스 속도)을 측정합니다.

### 일반적인 패턴
- 훈련은 대량의 게임 에피소드가 필요합니다 (10k+).
- 모델은 주기적으로 체크포인트에 저장됩니다.
- 평가는 훈련과 분리되며 결정론적 정책을 사용합니다.

## 의존성
### 내부
- `src/gym/` - 훈련 환경

### 외부
- `torch` - 신경망 프레임워크
- `numpy` - 벡터 연산
- `tqdm` - 진행 표시
