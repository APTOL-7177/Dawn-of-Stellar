# 퀘스트 시스템

## 목적
게임의 퀘스트 관리 시스템. 플레이어가 수행할 수 있는 부가 임무를 정의하고 추적합니다. 퀘스트 진행, 목표 달성, 보상 지급을 관리합니다.

## 주요 파일
| 파일 | 설명 |
|------|------|
| quest_manager.py | 퀘스트 상태 관리 및 진행 추적 |

## AI 에이전트를 위한 가이드
### 이 디렉토리에서 작업할 때
- 퀘스트는 상태를 가집니다 (미시작, 진행 중, 완료, 실패).
- 각 퀘스트는 목표(목표 몬스터 처치, 아이템 수집 등)를 가집니다.
- 진행은 플레이어 행동을 감지하여 자동 업데이트됩니다.
- 완료 시 보상(골드, 경험치, 아이템)을 지급합니다.

### 테스트 요구사항
- 퀘스트 상태 전환이 정확한지 검증합니다.
- 목표 달성 감지가 정확한지 확인합니다.
- 보상 지급이 올바르게 적용되는지 검증합니다.
- 완료 후 퀘스트 목록 업데이트를 확인합니다.

### 일반적인 패턴
- 퀘스트는 YAML 정의를 따릅니다.
- 진행은 카운트(처치 수, 수집 수)로 추적됩니다.
- 완료 조건은 "100% 달성" 또는 "선택적" 목표를 포함할 수 있습니다.

## 의존성
### 내부
- `src/character/` - 플레이어 경험치, 골드
- `src/equipment/` - 보상 아이템
- `src/persistence/` - 퀘스트 진행 저장

### 외부
- `pyyaml` - 퀘스트 정의 로드
- `pydantic` - 퀘스트 모델 검증
