# 밸런스 점검

## 1. 캐릭터 스탯 분포 확인
// turbo
```bash
python -c "
import yaml, pathlib
chars = []
for f in sorted(pathlib.Path('data/characters').glob('*.yaml')):
    d = yaml.safe_load(f.read_text(encoding='utf-8'))
    bs = d.get('base_stats', {})
    total = sum(v for v in bs.values() if isinstance(v, (int, float)))
    chars.append((d.get('class_name','?'), total, bs.get('hp',0), bs.get('physical_attack',0), bs.get('speed',0)))
chars.sort(key=lambda x: -x[1])
print(f'{'직업':<12} {'합계':>6} {'HP':>5} {'공격':>5} {'속도':>5}')
print('-'*40)
for name, total, hp, atk, spd in chars:
    print(f'{name:<12} {total:>6.0f} {hp:>5} {atk:>5} {spd:>5}')
"
```

## 2. 스킬 MP 비용/배율 분포 확인
// turbo
```bash
python -c "
import yaml, pathlib
skills = []
for f in pathlib.Path('data/skills').glob('*.yaml'):
    d = yaml.safe_load(f.read_text(encoding='utf-8'))
    if not d: continue
    mp = d.get('costs',{}).get('mp', 0)
    mult = 0
    for e in d.get('effects', []):
        if isinstance(e, dict) and 'multiplier' in e:
            mult = max(mult, e['multiplier'])
    if mp or mult:
        skills.append((d.get('id','?'), d.get('type','?'), mp, mult))
skills.sort(key=lambda x: -x[3])
print(f'{'ID':<25} {'타입':<15} {'MP':>4} {'배율':>5}')
print('-'*55)
for sid, stype, mp, mult in skills[:30]:
    print(f'{sid:<25} {stype:<15} {mp:>4} {mult:>5.1f}')
print(f'... total {len(skills)} skills')
"
```

## 3. 스킬 효율(배율/MP) 이상치 탐지
// turbo
```bash
python -c "
import yaml, pathlib
skills = []
for f in pathlib.Path('data/skills').glob('*.yaml'):
    d = yaml.safe_load(f.read_text(encoding='utf-8'))
    if not d: continue
    mp = d.get('costs',{}).get('mp', 0)
    mult = max((e.get('multiplier',0) for e in d.get('effects',[]) if isinstance(e,dict)), default=0)
    if mp > 0 and mult > 0:
        skills.append((d.get('id','?'), mp, mult, mult/mp))
skills.sort(key=lambda x: -x[3])
print('높은 효율 (배율/MP):')
for sid, mp, mult, eff in skills[:10]:
    print(f'  {sid}: {mult:.1f}x / {mp}MP = {eff:.3f}')
print('\\n낮은 효율:')
for sid, mp, mult, eff in skills[-5:]:
    print(f'  {sid}: {mult:.1f}x / {mp}MP = {eff:.3f}')
"
```

## 4. 결과 분석
이상치가 발견되면 해당 스킬/캐릭터의 YAML을 조정한다.
밸런스 기준:
- 기본 공격 스킬: 배율 1.5~2.5x, MP 5~15
- 강 공격 스킬: 배율 3.0~5.0x, MP 10~25
- 궁극기: 배율 5.0~10.0x, MP ~80+
